# LP Creator 決定記録

## DECISION-001: 3段階構成の採用（2026-03-04）

### 背景
当初は「デモ版」と「本格版」の2段階だったが、セミナーでの実用性を考慮して3段階に変更。

### 決定内容
セミナー簡易版 → デモ版 → 本格版（有料）の3段階で進化させる。

| Stage | 名称 | 主な機能 | 速度 |
|-------|------|---------|------|
| 1 | セミナー簡易版 | コピー生成 + HTML/CSSデザインのみ | 30秒以内 |
| 2 | デモ版 | + 参考URL分析 + ダウンロード | 数分 |
| 3 | 本格版（有料） | + AI画像生成 + 認証 + 課金 | 5〜10分 |

### 理由
- 画像生成に時間がかかるため、セミナーではまずコピー+デザインだけを即座に見せたい
- ただし画像生成が5〜10分で済むなら、セミナー中に段階的に見せる演出も可能
- 「30秒で基本LP → 5分後に画像付き完成版」という二段階デモが効果的

## DECISION-002: 販売形態は未定（2026-03-04）

### 背景
当初は月額サブスク（フリー/ベーシック/プロ）を計画していた。

### 決定内容
販売形態（買い切り7万円前後 / 月額サブスク / 併用）は本格版の完成後に決定する。

### 理由
- まず3段階の機能を作ってから、市場の反応を見て販売形態を決めたい
- セミナーでの反応次第で最適な価格・形態が変わる可能性がある

---

## DECISION-003: セミナー演出パターン（2026-03-04）

### 決定内容
セミナーでは以下の演出を想定：

```
1. 「30秒でLP完成！」→ 簡易版でコピー+デザインを即座に見せる
2. 「さらにAIが画像も自動で作ります」→ 裏で画像生成を走らせる
3. 5〜10分後「完成版がこちらです！」→ 画像付きフルLPを見せる
```

### 理由
- 5〜10分で画像生成が完了するなら、セミナー内で段階的に見せる価値がある
- 「進化する過程」を見せることで、本格版の価値を実感してもらえる
