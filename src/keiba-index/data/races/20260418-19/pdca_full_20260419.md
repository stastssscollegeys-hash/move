### 改善A【最重要・即時対応】: 阪神G3ダート重賞の源泉レース必須化

**根本原因:**
アンタレスSを源泉レース対象に含めなかった。
「G3ダート重賞＋1番人気信頼度中程度」はアスメシ式 S〜A級の荒れパターンに合致する。

**アクション:**
- 毎週の源泉レース選定ルールに「阪神G3ダート（アンタレスS等）を優先選定対象」として明示追加
- 選定判断基準の更新:

```
現状: 牝馬G3・ハンデ戦・多頭数 → 源泉対象
改善: + ダートG3（1番人気4倍台以下） → 源泉対象
     + 「1番人気来るが3着大穴」パターンの3連複特化買いを定式化
```

### 改善B【最重要】: program.yaml生成の精度修正

**根本原因:**
- 中山土曜11R → 「スプリングS(G2)」と誤記（実際は「中山グランドジャンプ(J・G1)」）
- 福島土曜11R → 「福島民報杯(L)」は4/12開催で4/18は別レース

**アクション:**
- program.yaml生成時に必ずJRA公式の番組表(jra.go.jp/keiba/calendar)と照合するステップを追加
- `keiba-predictor-ss` スキルのPhase 1（番組取得）をJRA公式URLから直接fetchするよう改修

```yaml
# keiba-predictor-ss Phase 1 改善案
source: "https://www.jra.go.jp/keiba/calendar{year}/{month}/{date}.html"
validation: レース名・距離・グレードをAPIと照合してから保存
```

### 改善C【高優先】: G1同点スコア時タイブレーカー

**根本原因:**
バステール(18番)とロブチェン(4番)が135pt同点。EVのみでバステールを本命にしたが、外枠(8枠18番)が致命的不利だった。

**タイブレーカールール（新規策定）:**

```
優先順位:
1. 枠順補正スコア（中山G1 8枠 → -5pt追加）
2. G1出走実績（重賞2着以上の直近2走）
3. 前走レベル差補正
4. EV（参考値として最後）
```

**結果:**
- バステール 135pt - 5pt(外枠) = 130pt
- ロブチェン 135pt + 0pt = 135pt
→ タイブレーカー後: ロブチェン本命が正解だった

---

### 改善D【高優先】: G1対抗馬の単勝少額必須化

**根本原因:**
ロブチェンはEV-33%のためワイド組みしかしなかったが、単勝も買っておけば400円×3,000円分=3,000円以上回収できた。

**新ルール:**
```
G1での資金配分:
  ◎単勝: 40%
  ○単勝: 20%（EVマイナスでも同点評価の対抗は必ず少額確保）
  ワイド◎-○: 20%
  3連複◎○▲: 20%
```

---

### 改善E: 福島牝馬S型「大穴1着フォーメーション」追加

**根本原因:**
3連複フォーメーション「2〜3番人気 → 1〜5番人気 → 全頭」では1着コガネノソラ(大穴)をカバーできない。

**新戦略（2段構成）:**
```
メインフォーメーション（現行維持）:
  1〜3番人気 → 2〜7番人気 → 全頭   2,000円

追加「大穴1着対応」フォーメーション（新規）:
  6〜10番人気(各) → 2〜3番人気 → 全頭   500円×3点=1,500円

ワイド保険（現行維持）:
  2〜3番人気BOX / 3〜5番人気BOX   300円
```

---

### 改善F: 内枠理論の見直し

**根本原因:**
京葉S で1・3着が7枠（外枠）から。内枠(1〜4番)のみの購入では取れなかった。

**修正:**
```
現行: 1〜4番枠のみ購入
改善: 1〜6番枠 + 「展開優位な外枠先行馬」を条件追加
     ダート1200m・1800mでは「5〜7枠でも前々に行ける馬」を除外しない
```

---

### 改善G: 週間源泉レース全数スキャンの導入

**根本原因:**
源泉レースの選定が「知っているレース」「人気重賞」に偏りがち。アンタレスSのような「毎年恒例G3」を見落とした。

**新プロセス:**

```
Phase 0（新規）: 週間全重賞スキャン
1. JRA公式から当該週末の全重賞・リステッド一覧を取得
2. 各レースを荒れスコアで自動評価:
   - G3以下: +3pt
   - ダート重賞: +2pt
   - 牝馬限定: +2pt
   - ハンデ戦: +3pt
   - 頭数16以上: +1pt
   - 1番人気単勝5倍以上: +3pt
3. 合計8点以上 → S級（必選）
4. 合計5〜7点 → A級（推奨）
5. 合計4点以下 → B級（任意）

アンタレスS事後スコア:
  G3 +3, ダート +2, 頭数不明(+0), 1人気4倍台 +1 = 6点 → A級（本来は選定すべきだった）
```
