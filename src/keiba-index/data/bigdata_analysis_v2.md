### 8-2. 予想精度向上のための重点5因子（v3.2版）

#### 因子1: 脚質×コース適性（sc[3]）【最重要】

**コースフラグ自動適用リスト:**
- 中山2000m×逃げ → 自動-2pt（逃げ勝率3.3%）
- 阪神2000m×逃げ → 自動+2pt（逃げ勝率23.7%・単回305%）
- 阪神1200m×逃げ → 自動+2pt（逃げ勝率29%・最強コース）
- 全コースで「追込は-2pt以上」
- 阪神芝2000m×追込 → 自動-3pt（勝率0%・絶対消し）
- 中山ダート各距離×逃げ → 自動+1pt（ダートは逃げ有利）

#### 因子2: 枠順×コース×頭数×開催週（sc[7]）

**優先チェックリスト:**
- 中山2500m: 1-2枠+2pt、4枠・7枠-2pt（有馬記念等）
- 阪神芝2000m: 1枠・3枠+2pt（大阪杯等）
- 阪神芝1600m: 6枠+2pt、3枠-2pt（マイラーズC等）
- ダート全般: 外枠有利（芝スタートは特に顕著）
- 開催1-2週: 内枠に+1pt追加
- 阪神道悪: 内枠から外枠に逆転

#### 因子3: 騎手×競馬場適性（sc[5]）【即効性最高】

**必須チェックポイント:**
- 川田×阪神芝 = +3pt（勝率33.8%・全コース最高水準）
- 川田×阪神ダ1400m = +3pt（勝率37.3%・全コース最高水準）
- ルメール×中山 = +3pt（勝率23.2%）
- 横山武史×中山 = +2pt（勝率19.6%）
- 横山和生×中山2500m = 穴フラグ+4pt（単回628%）
- **坂井瑠星×芝道悪 = -3pt（勝率2.3%・即消し）**
- 武豊×中山2500m = +2pt（単回226%）

#### 因子4: 血統×馬場状態（sc[6]+sc[16]）

**道悪時の必須チェック:**
- **エピファネイア産駒: -2pt（最重要。-7.3pt実績）**

- キタサンブラック産駒: +1pt（重馬場）
- ダイワメジャー産駒: +1pt（重馬場）
- ロードカナロア産駒: -1pt（道悪・牝馬特に）
- モーリス産駒: +2pt（稍重がベスト）

#### 因子5: 荒れスコア×EV戦略（sc[11]連動）

**レース前荒れスコア計算後:**
- S級(8点+): 3連単フォーメーション購入を最優先
- A級(5-7点): 大穴馬を相手に追加
- C級(0-2点): 1-2番人気軸複勝/ワイドで安定回収
- **大阪杯特例: G1=0点でも1番人気EV悪い(2019以降0勝) → sc[11]-1**
