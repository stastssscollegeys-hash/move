```
荒れスコア = クラス点 + コース点 + 条件点 + 頭数点 + 人気点

クラス点:
  G3以下 = +3, G2 = +2, G1 = 0（G1は実力通りの決着多）

  ダート重賞 = +2

  ハンデ戦 = +3

人気点:
```
