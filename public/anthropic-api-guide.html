Anthropic API キー取得ガイド

AI分析機能（トレンド判定・ターゲット分析）に必要なAPIキーの取得手順です。

Anthropic Console を開く →
💡 エラーページが表示される場合
APIキーの作成画面やクレジット追加画面でエラーページが表示されることがあります。
その場合はブラウザのシークレットウィンドウ（プライベートウィンドウ）で Anthropic Console にアクセスし直すと解決できることがあります。
ブラウザの拡張機能やキャッシュが干渉している可能性があるためです。

1Anthropic Consoleにアクセス

https://console.anthropic.com/ にアクセスし、アカウントを作成またはログインします。

2APIキーを作成

ダッシュボードの「Settings」→「API Keys」を開きます。

「Create Key」をクリックし、名前（例: youtube-research）を入力して作成します。

表示されたキーをコピーします（sk-ant-... で始まる文字列）。

キーは作成時の1回しか表示されません。必ずコピーして安全な場所に保存してください。

3クレジットを追加

「Settings」→「Billing」でクレジットカードを登録し、APIクレジットを追加します。

最初は $5〜10 程度でOKです。

料金について

項目内容
使用モデルClaude Sonnet（高速・低コスト）
入力$3 / 100万トークン
出力$15 / 100万トークン
1回の分析約 $0.01〜0.05（1〜5円程度）
1回の分析は数円程度です。$5のクレジットで100回以上分析できます。

キーを取得したら、ツール画面の「APIキー設定」に貼り付けて保存してください。
