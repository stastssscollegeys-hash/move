APIキー取得ガイド

このツールを使うには、YouTube Data API キーとAnthropic API キーが必要です。

1. YouTube Data API キーの取得

1Google Cloud Consoleにアクセス

https://console.cloud.google.com/ にアクセスし、Googleアカウントでログインします。

2新しいプロジェクトを作成

画面上部のプロジェクト選択メニューから「新しいプロジェクト」をクリックします。

プロジェクト名は任意（例: youtube-research）で作成します。

3YouTube Data API v3 を有効化

左メニュー「APIとサービス」→「ライブラリ」を開きます。

検索バーに YouTube Data API v3 と入力し、表示された項目をクリックします。

「有効にする」ボタンをクリックします。

4APIキーを作成

左メニュー「APIとサービス」→「認証情報」を開きます。

「+ 認証情報を作成」→「APIキー」をクリックします。

作成されたAPIキーをコピーします（AIza... で始まる文字列）。

5（推奨）APIキーを制限

作成したキーの「キーを制限」をクリックします。

「APIの制限」→「キーを制限」→ YouTube Data API v3 のみ選択して保存します。

キーを制限すると、万が一キーが漏洩しても他のGoogleサービスへの不正利用を防げます。

料金について

項目内容
無料枠1日あたり 10,000 ユニット
動画検索1回 = 100 ユニット
動画詳細取得1回 = 1 ユニット/動画
チャンネル情報1回 = 1 ユニット/チャンネル
1回の分析約 120〜200 ユニット
1日の分析回数目安約 50〜80回（無料枠内）
通常の個人利用であれば無料枠で十分です。クレジットカードの登録は不要です。

2. Anthropic API キーの取得

1Anthropic Consoleにアクセス

https://console.anthropic.com/ にアクセスし、アカウントを作成またはログインします。

2APIキーを作成

ダッシュボードの「Settings」→「API Keys」を開きます。

「Create Key」をクリックし、名前（例: youtube-research）を入力して作成します。

表示されたキーをコピーします（sk-ant-... で始まる文字列）。

キーは作成時の1回しか表示されません。必ずコピーして安全な場所に保存してください。

3クレジットを追加

「Settings」→「Billing」でクレジットカードを登録し、APIクレジットを追加します。

最初は $5〜10 程度でOKです。

💡 エラーページが表示される場合
APIキーの作成画面やクレジット追加画面でエラーページが表示されることがあります。
その場合はブラウザのシークレットウィンドウ（プライベートウィンドウ）で Anthropic Console にアクセスし直すと解決できることがあります。
ブラウザの拡張機能やキャッシュが干渉している可能性があるためです。

料金について

項目内容
使用モデルClaude Sonnet（高速・低コスト）
入力$3 / 100万トークン
出力$15 / 100万トークン
1回の分析約 $0.01〜0.05（1〜5円程度）
1回の分析は数円程度です。$5のクレジットで100回以上分析できます。

3. キーの設定方法

ツール画面上部の「APIキー設定」を開き、取得した2つのキーを入力して「キーを保存」をクリックします。

キーはブラウザのローカルストレージに保存されます。サーバー側には保存されません。
