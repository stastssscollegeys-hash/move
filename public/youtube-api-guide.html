YouTube Data API キー取得ガイド

YouTube動画の検索・分析に必要なAPIキーの取得手順です。

Google Cloud Console を開く →

1Google Cloud Consoleにアクセス

https://console.cloud.google.com/ にアクセスし、Googleアカウントでログインします。

2新しいプロジェクトを作成

画面上部のプロジェクト選択メニューから「新しいプロジェクト」をクリックします。

プロジェクト名は任意（例: youtube-research）で作成します。

3YouTube Data API v3 を有効化

左メニュー「APIとサービス」→「ライブラリ」を開きます。

検索バーに YouTube Data API v3 と入力し、表示された項目をクリックします。

「有効にする」ボタンをクリックします。

4APIキーを作成

左メニュー「APIとサービス」→「認証情報」を開きます。

「+ 認証情報を作成」→「APIキー」をクリックします。

作成されたAPIキーをコピーします（AIza... で始まる文字列）。

5（推奨）APIキーを制限

作成したキーの「キーを制限」をクリックします。

「APIの制限」→「キーを制限」→ YouTube Data API v3 のみ選択して保存します。

キーを制限すると、万が一キーが漏洩しても他のGoogleサービスへの不正利用を防げます。

料金について

項目内容
無料枠1日あたり 10,000 ユニット
動画検索1回 = 100 ユニット
動画詳細取得1回 = 1 ユニット/動画
チャンネル情報1回 = 1 ユニット/チャンネル
1回の分析約 120〜200 ユニット
1日の分析回数目安約 50〜80回（無料枠内）
通常の個人利用であれば無料枠で十分です。クレジットカードの登録は不要です。

キーを取得したら、ツール画面の「APIキー設定」に貼り付けて保存してください。
