## 基本ルール

### パブリックドメイン（著作権切れ）の基準

| 条件 | 期間 |
|------|------|
| 日本の著作物 | 著作者の死後70年 |
| 海外の著作物（基本） | 著作者の死後70年 |
| 海外の著作物（戦時加算対象） | 死後70年 + 約10年5ヶ月 |

**戦時加算**: 連合国国民（米英仏等）の著作物で、WW2前・中に作成されたものが対象。
**安全基準**: 著者没後80年以上ならほぼ確実にパブリックドメイン。

### 著作権で保護されるもの / されないもの

| 保護される | 保護されない |
|-----------|-------------|
| 特定の「表現」（文章、翻訳、イラスト） | 「アイデア」「思想」「事実」 |
| 翻訳書の文章 | 歴史的事実そのもの |
| 解説書の独自の構成・文体 | 哲学者の思想そのもの |
| YouTube動画のシナリオ・構成 | 宗教の教義そのもの |

## KDP（Amazon）ガイドライン要点

### AI使用時の申告ルール
| 使用方法 | 申告 |
|---------|------|
| AIが文章を生成 | 「AI生成テキスト」申告**必須** |
| AIが画像を生成 | 「AI生成画像」申告**必須** |
| AIでアイデア出し・校正 | 申告不要（AIアシスト扱い） |

### その他の重要ルール
- 1日3冊出版上限
- 宗教コンテンツ審査強化（特にイスラム教）
- 健康・金融の断言禁止
- ヘイトスピーチ即アカウント停止
- テロリズムの擁護は明確に禁止

## 実践チェックリスト

漫画制作前に必ず確認：

- [ ] 著者の没年を確認（死後70年+戦時加算で80年以上が安全）
- [ ] 特定の翻訳書の表現をコピーしていないか
- [ ] 漫画・イラストは完全オリジナルか
- [ ] 歴史的事実/思想の解説であり、特定の現代著作の要約ではないか
- [ ] 宗教・政治テーマは客観的・学術的な立場を維持しているか
- [ ] AI生成コンテンツの申告は適切か
- [ ] YouTubeの構成・シナリオをそのまま流用していないか
- [ ] 健康・金融テーマで断言表現を使っていないか
- [ ] 免責事項が必要なテーマには記載しているか
