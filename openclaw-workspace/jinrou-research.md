# 🐺 人狼ゲーム 徹底リサーチ

## 📖 概要
- **正式名称**: 汝は人狼なりや?（Are You a Werewolf?）
- **起源**: 1986年、ソ連モスクワ大学の学生ドミトリー・ダビドフが「マフィア」として考案
- **ジャンル**: 会話型推理パーティーゲーム
- **プレイ人数**: 7〜20人程度（役職構成による）
- **必要なもの**: 役職カード、GM（ゲームマスター）1名

---

## 🎮 基本ルール

### ゲームの流れ
1. **準備**: GMが各プレイヤーに役職カードをランダムに配る（他人には見せない）
2. **夜フェイズ**: 全員目を閉じ、人狼が襲撃先を選ぶ → 占い師が1人を占う
3. **昼フェイズ**: 犠牲者発表 → 生存者で議論 → 投票で1人を処刑
4. **繰り返し**: 夜→昼→夜→昼… を繰り返す

### 勝利条件
- **村人陣営**: 人狼を全員処刑すれば勝ち
- **人狼陣営**: 生存人狼数 ≧ 生存村人数 になれば勝ち

### 重要ルール
- 死亡者は一切発言・ジェスチャー禁止
- 自分の役職カードは見せてはいけない（口頭で宣言はOK）
- 嘘は自由（村人側も人狼側も）

## 🃏 基本役職一覧

### 村人陣営
| 役職 | 能力 |
|------|------|
| **村人（市民）** | 特殊能力なし。多数派 |
| **占い師（予言者）** | 毎晩1人を占い、人狼かどうか判定 |
| **霊能者（霊媒師）** | 処刑された人が人狼だったか判定 |
| **狩人（騎士）** | 毎晩1人を人狼の襲撃から護衛 |
| **共有者** | 2人1組。互いが村人だと確認できる |
| **ハンター** | 死亡時に1人を道連れにできる |
| **猫又** | 襲撃死→人狼1人道連れ、処刑死→ランダム道連れ |

### 人狼陣営
| 役職 | 能力 |
|------|------|
| **人狼** | 毎晩1人を襲撃。人狼同士は互いを認識可能 |
| **狂人（裏切り者）** | 人間だが人狼側。占い・霊能では「人間」判定 |
| **狂信者** | 狂人の強化版。人狼が誰か分かる |
| **黒猫** | 処刑されると村人1人を道連れ |

### 第三陣営
| 役職 | 能力 |
|------|------|
| **妖狐** | 人狼に襲撃されても死なない。占われると死ぬ。ゲーム終了時に生存していれば勝ち |

## 🗣️ 用語集
- **CO（カミングアウト）**: 自分の役職を宣言すること
- **対抗**: 他人のCOに対して同じ役職をCOすること
- **吊る**: 投票で処刑すること
- **黒/白**: 人狼疑い/人間判定
- **ライン**: 人狼同士のつながり
- **ロラ（ローラー）**: 同役職の複数CO者を全員処刑すること
- **GM**: ゲームマスター（司会進行役）

## 📱 人狼アプリの仕組み

### アプリの主な種類

#### 1. オンライン対戦型
- **人狼ジャッジメント**: テキストチャットで議論。自動進行。50種以上の役職
- **人狼殺**: ボイスチャットで議論。声のトーンも推理材料に
- **人狼はウソ月**: イラスト重視のカジュアル系

#### 2. 対面プレイ補助型（GM代行アプリ）
- スマホがGMの代わりに進行を管理
- 役職配布・夜のアクション管理・タイマーなどを自動化
- カードを持っていなくてもプレイ可能

#### 3. 1人用・AI対戦型
- CPUキャラと対戦するシングルプレイ
- 練習用として人気

### アプリの基本機能
- **役職ランダム配布**: 公平な役職割り当て
- **夜フェイズの秘密処理**: 各役職の行動を個別に処理
- **タイマー管理**: 議論時間の制限
- **投票システム**: 匿名/記名投票
- **ログ管理**: 過去の発言・投票記録の閲覧
- **マッチング**: オンラインでのプレイヤー募集

### アプリならではの特徴
- GMが不要（アプリが自動進行）
- 少人数でもプレイ可能（オンラインマッチング）
- 役職が自動管理されるのでミスがない
- チャット/ボイスで遠隔プレイ可能

## 🎭 人狼の戦略・テクニック

### 村人側の基本戦略
- **占い師のCOタイミング**: 早すぎると人狼に狙われ、遅すぎると情報が出ない
- **ラインを読む**: 誰が誰を庇っているか、投票パターンの分析
- **論理的整合性**: 発言の矛盾を突く

### 人狼側の基本戦略
- **潜伏**: 目立たず村人に紛れる
- **騙り（かたり）**: 占い師などの役職を偽装して情報を撹乱
- **ライン切り**: 仲間の人狼を疑うフリをして信用を得る
