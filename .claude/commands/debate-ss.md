# AI Debate SS

3人のAIペルソナが3ラウンドのディベートを行い、テーマに対する多角的な視点と最終合意を導き出します。

## 引数の解析

ユーザー入力: `$ARGUMENTS`

- テーマが空の場合 → ユーザーにテーマを質問する
- `--roles` がない場合 → デフォルト（批判家/クリエイター/マーケッター）を使用
- `--roles ビジネス` → CEO/CFO/CTO
- `--roles ユーザー` → 初心者/パワーユーザー/離脱ユーザー
- `--roles X,Y,Z` → カスタム役割
- `--rounds N` がない場合 → デフォルト3ラウンド

## 役割定義

### デフォルト（クリエイティブ）
```
役割1: 批判家（クリティカルシンカー）
  視点: 論理・正確性・リスク・根拠
  口調: 鋭く、冷静に、「本当にそうか？」と問いかける

役割2: クリエイター（独創的な発想家）
  視点: 新規性・面白さ・感情・ストーリー
  口調: 情熱的に、ワクワクを伝える、「こうしたらもっと面白い！」

役割3: マーケッター（現実的な戦略家）
  視点: ターゲット・市場・ROI・行動喚起
  口調: 数字とデータに基づき、「で、誰が買うの？」と現実を突く
```

## 実行手順

### Step 1: テーマと役割の確定

テーマと役割をユーザーに確認する。確認不要であればそのまま進む。

### Step 2: Round 1 - 独立提案

3つのTaskサブエージェント（subagent_type: general-purpose, model: sonnet）を**並列**で起動する。

各エージェントへのプロンプト:
```
あなたは「{役割名}」としてディベートに参加しています。

## あなたの役割
{役割の詳細説明}

## テーマ
{テーマ}

## 指示
このテーマについて、あなたの役割の視点から意見を述べてください。
- 結論を最初に1文で述べる
- 理由を3つ挙げる
- 具体例や比喩を1つ以上含める
- 800字以内で簡潔にまとめる
- 他の参加者の意見はまだ見えません。自由に発想してください。
- リサーチ不要。あなたの知識と視点だけで回答してください。
```

3つの結果を受け取ったら、以下のフォーマットでユーザーに表示:

```
### Round 1: 独立提案

**{役割1}**:
{出力}

**{役割2}**:
{出力}

**{役割3}**:
{出力}
```

### Step 3: Round 2 - 批判的分析

Round 1の3人の意見を含めて、再度3つのTaskサブエージェントを**並列**で起動。

各エージェントへのプロンプト:
```
あなたは「{役割名}」としてディベートのRound 2に参加しています。

## あなたの役割
{役割の詳細説明}

## Round 1での全員の意見
{Round 1の3人分の出力をここに含める}

## 指示
Round 1の意見を読んで、以下を行ってください：
- 他の2人の意見への反論または賛同（誰のどの点に対してか明記）
- 自分のRound 1意見の修正・深化
- 新たに気づいたポイント
- 800字以内で簡潔にまとめる
```

### Step 4: Round 3 - 合意形成

Round 1+2の議論を含めて、再度3つのTaskサブエージェントを**並列**で起動。

各エージェントへのプロンプト:
```
あなたは「{役割名}」としてディベートの最終ラウンドに参加しています。

## あなたの役割
{役割の詳細説明}

## これまでの議論
### Round 1（独立提案）
{Round 1の3人分の出力}

### Round 2（批判的分析）
{Round 2の3人分の出力}

## 指示
2ラウンドの議論を踏まえて、最終見解を述べてください：
- 3人で合意できるポイントを挙げる
- まだ対立が残るポイントを挙げる
- あなたが譲れる点と譲れない点を明確にする
- テーマに対する具体的な推奨アクションを提案する
- 600字以内で簡潔にまとめる
```

### Step 5: 最終レポート生成

3ラウンドの結果を統合して、以下のフォーマットで最終レポートを出力:

```markdown
---

## ディベート最終レポート

### テーマ: {テーマ}
### 参加者: {役割1} / {役割2} / {役割3}

---

### Round 1: 独立提案
{各役割の要約}

### Round 2: 批判的分析
{各役割の要約}

### Round 3: 合意形成
{各役割の要約}

---

### 合意点
- {3人が合意したポイント1}
- {3人が合意したポイント2}
- {3人が合意したポイント3}

### 残った対立点
| 論点 | {役割1} | {役割2} | {役割3} |
|------|---------|---------|---------|
| {論点} | {立場} | {立場} | {立場} |

### 推奨アクション
1. {具体的アクション}
2. {具体的アクション}
3. {具体的アクション}

---
```

## 重要ルール

1. **各ラウンドの3エージェントは必ず並列（同時）で起動する**（効率化）
2. **サブエージェントにはリサーチさせない**（WebSearch/WebFetch禁止。知識のみで回答）
3. **各エージェントの出力は800字以内に抑える**（コンテキスト節約）
4. **最終レポートはメインコンテキストが生成する**（統合の質を担保）
5. **ユーザーに各ラウンドの結果を逐次表示する**（プロセスを楽しめるように）
