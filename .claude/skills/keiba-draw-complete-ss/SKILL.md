## Step 1｜枠順確定後 予想再評価＆最終予想

### 実行内容
1. **事前予想を参照**（存在する場合）
2. **枠番補正を適用**
   - 東京芝系: 1〜5枠優遇・8枠外枠補正（-10〜-20点）
   - 競馬場・コースに応じてメモリ `keiba_venue_data.md` 参照
3. **AI指数を再スコアリング**（枠順20点満点を更新）
4. **最終予想印を確定**

### 最終予想印テーブル（必須出力）

| 印 | 馬番 | 馬名 | 騎手 | AI指数 | 決め手 |
|----|------|------|------|--------|--------|
| ◎ | | | | | |
| ○ | | | | | |
| ▲ | | | | | |
| △ | | | | | |
| △紐 | | | | | |

### 買い目設計（2層型・8点・10,000円が基本）

**保護層 3,000円**（ワイドで元本50〜100%を守る網）
- ワイド 軸-相手1・軸-相手2・相手1-相手2 ／ 3点ボックス

**攻め層 7,000円**（馬連本線で300〜500%を狙う）
- 単勝 軸 ／ 1点
- 馬連 軸→相手複数 ／ 1頭軸流し
- 3連複 軸-本命相手-穴 ／ フォーメーション

> 参照: `memory/keiba_betting_strategy.md`

## Step 2｜SNS投稿案 Word docx 生成

### ファイル構成
- スクリプト: `gen_YYYYMMDD_レース名.py`
- 保存先: `C:\Users\User\Desktop\競馬予想レポート\YYYYMMDD\`
- 出力: `YYYYMMDD_レース名_SNS投稿案.docx`

### docx 必須セクション

```
SECTION 1: 最終予想印 一覧テーブル
SECTION 2: コース特性
SECTION 3: 有力馬個別診断（印ごとに詳細コメント）
SECTION 4: 2層型買い目設計（馬番表記・流し/フォーメーション記法）
SECTION 5: 的中シナリオ（①〜④）
SECTION 6: SNS投稿案
  ├── X投稿 全6本（長文・認証済みアカウント向け）
  ├── Threads投稿 全3本
  └── Note記事 全12セクション（無料・全文）
```

## Step 3｜SNS予想印インフォグラフィック画像生成（1枚絵・9:16）

X/Threads投稿に添付する「予想印が一目で分かる画像」を1枚生成する。
Note記事用サムネイル（Step 4・keiba-thumbnail-ss）とは別物で、こちらは
**印一覧・買い目まで含めた縦長インフォグラフィック**。

### 実行方法
```
スキル chatgpt-image-devtools-ss を呼び出す（CDP直結方式）
node .claude/skills/chatgpt-image-devtools-ss/scripts/cdp_chatgpt.mjs batch <manifest.json>
```

### 確定フォーマット（七夕賞2026で確立・関屋記念/東海ステークス2026で継承確認済み）

- **アスペクト比: 9:16**（縦長ポートレート、SNS投稿カード用）
- **スタイル: 和風ファンタジー×アニメ調イラスト**（写実的な実在人物・馬は描かない）
- **参照画像を必ず添付**（`attachImages`）: 直近で確立した最良版の画像
  （例: `20260711/七夕賞_SNS投稿画像_最終版_chatgpt.png`）をレイアウト・
  マスコットデザインの構図参照として1枚添付し、プロンプト冒頭で
  「添付画像を構図・レイアウトの参照として使ってください」と明記する

### 固定するレイアウト構造（毎回同じ）
```
①最上部: 金色の筆文字風メインタイトル（レース名＋グレード）
②その下: 開催日・競馬場・コース（白文字）
③中央: 疾走する騎手＋馬のアニメ調イラスト（背番号=◎の馬番）
④イラスト下: 金色のキャッチコピー（レーステーマに合わせた一言）
⑤左下: 予想印ボックス（◎○▲△穴＋馬番＋馬名、濃紺背景×金枠）
⑥予想印ボックス右隣: 「◎の理由」ボックス（本命の決め手を2〜3文）
⑦右下: アスメシ茶色馬マスコット（ピンク帽子・青タンクトップ「アスメシ」・
   ガッツポーズ）※参照画像と同一デザインを踏襲
⑧最下部: 買い目ボックス（濃紺背景×金枠のテーブル状、金額まで正確に記載）
```

### レースごとに変えるもの（テーマの描き分け）
- 季節・天候・コース特性に応じた装飾モチーフと配色を変更する
  （例: 七夕賞＝天の川・笹の葉・短冊／関屋記念＝大雨の夜・雷・雨だれ提灯／
  東海ステークス＝灼熱の夕焼け・砂塵・炎の装飾）
- 騎手の勝負服カラーもテーマに合わせる（関屋記念＝ネイビー×シルバー、
  東海ステークス＝赤×ゴールド等）
- キャッチコピーもテーマに合わせて毎回書き下ろす
- ①〜③⑤〜⑧の構造とアスメシマスコットのデザインは**変更しない**

### プロンプト作成の必須事項
- 印一覧・買い目の数字/馬名/金額は**一字一句正確に**指定し、「読み間違えの
  ないよう大きめのフォントで」と明記する
- 「実在の騎手・馬をリアルに描写せず、イラスト・アニメ風の抽象化された
  キャラクターとして描いてください」を必ず入れる
- 品質目標として「プロのSNS競馬予想アカウントが使うレベルの高品質
  インフォグラフィック」と明記する

### 保存先
`C:\Users\User\Desktop\競馬予想レポート\YYYYMMDD\images\<レース名>_marks.png`

## Step 5｜YouTube 動画制作

### ディレクトリ構成
```
C:\Users\User\Desktop\競馬予想レポート\レース名-video\
├── script.json              ← 20シーン narration/reading/image_content
├── generate_audio_multikey.js  ← Gemini TTS 5キーローテーション
├── generate_images_session.py  ← NanaBanana Pro ブラウザ自動化
├── prepare_render.js           ← audio/images→public/ コピー + ts生成
└── remotion-project/
    ├── src/
    │   ├── Root.tsx
    │   ├── SplitTelopOverlay.tsx   ← 字幕オーバーレイ
    │   ├── splitTelopData.ts       ← 自動生成
    │   └── scenesData.ts           ← 自動生成
    └── render.mjs
```

### 実行順序
```
1. script.json 作成（20シーン）
2. node generate_audio_multikey.js   （音声生成）
3. python generate_images_session.py （画像生成）
4. node prepare_render.js            （素材コピー＋ts生成）
5. Start-Process node render.mjs     （バックグラウンドレンダリング）
6. 完了確認: oaks2026_output.mp4 のサイズ確認
```

### 動画仕様
- 解像度: 1920×1080
- FPS: 30
- 目標尺: 7〜9分（シーン数 × 平均20秒）
- 字幕: SplitTelopOverlay（フェードイン/アウト付き）

### 注意点
- PowerShell の `Start-Process` でバックグラウンド実行（timeoutを避けるため）
- `tail -5` パイプは使わない（SIGPIPEでnode死亡する）
- 画像生成はnon-persistentブラウザコンテキストで実行
