## Philosophy — なぜ競馬なのか（クオンツ投資研究所としての競馬）

> セミナー「AI時代の投資アルゴリズム ―競馬という研究室から―」2026年4月より落とし込み

### 競馬 vs 株式 — 現行AIで勝てるのはなぜ競馬か

| 比較軸 | 競馬 | 株式投資 |
|--------|------|---------|
| 変数の有限性 | **クローズドシステム**（距離・血統・枠・頭数…有限変数） | 無限のノイズ（SNS・CEOの発言・地政学） |
| 検証サイクル | **24時間で結果**（365倍速で仮説検証） | 数ヶ月〜1年 |
| AIの処理能力 | 1レース = 数万文字 → **現行AIで100%理解** | 有価証券報告書 = 1億文字 → 現行AIでは対応不可 |
| 現在の勝算 | **◎ 今すぐ戦える** | △ あと2〜3年待つ必要あり |

**結論**: 現行AI（Claude/GPT等）の性能のど真ん中が競馬。株式はいずれAIが解くが今ではない。

### AIの現在地（テキスト処理能力）

```
1万文字   → 理解度 100%（完璧）
10万文字  → 理解度  80%（実用レベル）
100万文字 → 理解度 60-70%（取りこぼし発生）
1億文字   → 現行AIでは対応不可 ← 株式投資に必要なレベル
```

競馬1レース分析は「数万文字」→ 現行AIの性能帯ど真ん中。

### クオンツ投資としての競馬

このスキルは「競馬予想」ではなく**「競馬市場で動くクオンツ投資」**である。

**クオンツ投資の本質:**
- 人間の感情（恐怖・強欲・熱狂）が生み出す価格の歪みをデータで発見
- 感情を排除し、数学・統計で機械的にかけ続ける
- 大衆の感情 → 歪んだオッズ → EV+(期待値プラス)の機会 → 淡々と購入

**競馬オッズ ≒ 株価の本質的同一性:**
```
人気馬のオッズ = 大衆の感情で歪む
人気株の株価 = 大衆の感情で歪む
↓
どちらも「感情による価格歪み」を統計で見つけて買う = クオンツ手法
```

### サンドボックス戦略（競馬→将来の株式移行）

```
現在(2026):  競馬でアルゴリズム・思想を鍛える
              ↓ 365倍速の検証サイクル
              ↓ 変数有限のクローズド環境
              ↓ 現行AIで完全処理可能
将来(2028+): 株式市場にアルゴリズム思想を転用
              ← 競馬で磨いたEV発見手法がそのまま使える
```

**先行利益の法則**: AGI登場前に手法を確立した者が最大の恩恵を受ける。

## Overview

JRA中央競馬の的中率を最大化し、回収率100%超えを目指す予想ツール。
**LightGBM ML (v44)** を核とした予測エンジンで、SNS投稿素材を一括生成する。

**MLバックテスト結果（LightGBM v44）:**
- train〜2024 / test 2025-26: Combined ROI **273.3%**
- 5シード全黒字 / Bootstrap P(>100%) = 100%

**ルールベース検証結果（PDCA37, 894R: 2026/1/4〜4/5）:**
- 複勝的中率: **69.7%**

**データ基盤:** `src/keiba-index/data/bigdata_analysis_v2.md`（2026-04-23 最新）
- 過去10年（2016-2026）× 年次重み付き
- 全16ファイル統合 / v3.2確定パラメータ適用済み

## SNS投稿フォーマット

### 口調の基本方針

**敬語＋親しみやすい温かみ（polite-warm）**
- 硬すぎず・フランクすぎない
- 絵文字を適度に使用（🍱🐴🎯🔥💪🎰✨🍜🎉）
- ハッシュタグ: `#競馬予想 #AI予想 #JRA` + レース名タグ
- **X投稿は認証済みアカウントのため文字数制限なし（長文OK）**

### 時系列の表現ルール（前日投稿が基本・2026-08-01確立）

**予想SNS投稿は「レース前日の夜に投稿する」ことを前提に書く。**
投稿文中の時制は投稿日（＝前日）視点で統一する:

| 対象 | 表現 | NG例 |
|------|------|------|
| レース当日 | 「明日15:25発走」「明日の〇〇S」 | ~~「本日15:25」「いよいよ本日」~~ |
| 投稿日当日のレース結果（馬場傾向等） | 「本日の札幌芝で確認」「本日の新潟で実測」 | ~~「昨日の札幌芝」~~ |
| タイトル | 「前日最終予想」 | ~~「直前最終予想」（当日朝投稿の場合のみ可）~~ |
| 結果報告投稿 | レース当日の夜に投稿 →「本日の〇〇レース」 | — |

- 当日朝に投稿する場合（実オッズ反映の最終確定版など）のみ「本日」「まもなく発走」を使う
- 前日の馬場傾向を根拠に使う場合は「本日の〇〇競馬場で実測」と書くことで
  「今日のレースを見て明日を予想している」ライブ感を演出できる

### 前日最終予想の構成ルール（2026-08-01確立・毎回適用）

**① 買い目の最終決定理由を必ず記載する**
最終予想投稿には「本日のレース結果（馬場傾向・実測データ）を受けて、
なぜこの買い目・この券種に最終決定したのか」の理由を明記する。
例:「本日の札幌芝は差し馬が3着内最多 → 差し馬3頭の上位独占予想なので

【当日実測 → 判断 → 券種選択】の因果を1〜3行で書く。

**② 投稿数は1レースあたり3〜6投稿に収める**

### 🔴 sc[8] ペース補正は「距離×ペース×馬場」の実測から出す（2026-09-27改定）

| ダ〜1200 | **+33.3pt** |
| **芝〜1200** | **+22.0pt**（重・不良は**+26.0pt**） |
| ダ1500-1600 | +21.8pt |

2026-09-27スプリンターズS（芝1200m・稍重・H）で◎○△を全部「追込」に置き、1着逃げ・2着先行・3着先行で

該当馬場に脚質のサンプルが無ければ馬場を広げて代用する（中立に落とすと逃げが不当に不利になる）。

### 🔴🔴 買い目設計の土台＝期待値（2026-09-27確立・ユーザー指定「期待値競馬を極めたい」）

```
│  期待値 ＝ オッズ × 的中率                                           │
```

出典: https://www.dulbea.org/info/keiba-expected-value/

**① 券種別の「狙うべき期待値」— まずこれで足切りする（期待値最大を機械的に取らない）**

| 券種 | 下限 | 確率の取り方 |

| 馬単 | **1.6〜2.5**（0.8未満は買わない） | 同上×順序 |
| 3連複 | **2.0〜3.0** | 3頭で1-3着を占める確率 |
| 3連単 | **2.0〜3.0** | 勝率×2着率×3着率 |

**② 的中率は絶対に主観で置かない。** 出典サイト自身が最大の弱点として

うちはここを潰す:

  必要なときはHarvilleの実測補正（λ2=0.80／λ3=0.70）を使う
- 配当は**当日の実オッズ**。推定配当は前日版のみ（外挿で1,000倍級の嘘が出るため当日は使わない）
- 実装: `kaime_select_live.py`（配当＝実オッズ・的中率＝実測帯）

**③ 期待値を上げる4手段**

4. ガードを通す（Σ(1/配当)≦1.0／本線は4.0倍以上／1点以上当たる確率10%以上／100円単位／規定額）
5. 推定配当に反比例で配分（どれが当たっても戻りが揃う）
6. 印は**買い目から導く**（◎=軸、○▲△=実際に買った相手を金額順、🔥=穴）。印と買い目がズレたら不合格

**⑤ 限界を忘れない（出典サイトの警告）**
- 期待値は理論値。馬場・展開・騎手・馬の気分のブレは織り込めない
- 直前でオッズが動く。期待値が高いと判断した時点で買うか、変動を許容範囲と決めておく
- **資金管理を優先する**。期待値が高いからと1レースに寄せない（[[keiba_bankroll_kelly]]：
  期待値マイナスなら配分をどう工夫しても破産確率は1。1点はケリー1/4が上限）

**6原則（X・Threads・Note・Word すべてで統一）:**

| # | ルール | 理由 |
|---|--------|------|
| 1 | **冒頭に「💰 買い目 合計◯点・◯円」を先出し** | 読者が最初に知りたいのは総額と点数。末尾だけに書くと見落とす |
| 2 | **券種ごとに【券種】ブロック化し、1行目に構造を書く**（「◎③軸 ― 相手 ⑧④⑭⑬」「BOX ③⑧④」「1着:③ 2着:⑧④ 3着:⑧④⑭」） | 1点ずつの羅列は読めない。軸・相手・流し幅が一目で分かる |
| 3 | **同額は「各◯円」で1行にまとめる**。金額差がある時だけ1点ずつ改行 | 行数を半分以下にできる |
| 4 | **馬番は丸数字①〜⑱**（金額・点数の数字と視覚的に区別）。馬名は印一覧で既出なので買い目では軸馬のみ1回併記 | 「3-8-4 900円」は数字が4種類並び読み間違う |
| 5 | 記号: 順不同（馬連・ワイド・3連複）は「-」、着順指定（馬単・3連単）は「→」、マルチは「⇔」、総流しは「全」 | 予想サイト・紙媒体と同じ規約で誤読ゼロ |
| 6 | 各ブロック末尾に（点数・小計）、最後に「役割: 本線／回収ライン／保険／穴」を1行。**全角スペースの桁揃えは禁止**（スマホで崩れる）、1行1情報 | 構成意図が伝わり、スマホ表示でも崩れない |

**表記例（キーンランドC 2026・B型10点）:**
```
💰 買い目 合計10点・10,000円
【3連複】◎③軸 ― 相手 ⑧④⑭⑬（6点 4,800円）
　③-⑧-④ 1,000円 / ③-⑧-⑭ 900円 / ③-⑧-⑬ 800円
　③-④-⑭ 800円 / ③-④-⑬ 700円 / ③-⑭-⑬ 600円
【ワイド】③-④ 2,000円 / ③-⑭ 1,700円（2点 3,700円）
【3連複・保険】⑧-④-⑭ 800円 / ③-⑧-⑪ 700円（2点 1,500円）
役割: 本線=3連複③軸 ／ 回収ライン=ワイド③-④ ／ ◎飛び保険=⑧-④-⑭ ／ 3重シグナル紐=⑪
```
- 従来の「3連複　3－8－11　500円（長い理由）」形式は廃止。理由は買い目の外（決定理由の段落）に書く
- 配当シミュレーション5パターン・7点/10,000円基準・馬番のみ（枠番禁止）の既存ルールはそのまま
- Threadsは同じ構造で圧縮（構造行＋「各◯円」行のみ、1点ずつの行は省略可）
- Note/Wordでは同内容を表（券種｜構造｜買い目｜金額）にしてもよいが、X用テキストは上記の行形式

## EV理論 — クオンツ的オッズ歪み発見の実装

```
┌─────────────────────────────────────────────────────────────────────┐
│ 🚨 2026-08-30 実測による重大な訂正                                   │
│  「モデルが市場より高く評価する馬＝妙味」という前提は、実測で        │
│  完全に否定された。むしろ乖離が大きいほど回収率が下がる。            │
└─────────────────────────────────────────────────────────────────────┘
```

**事前予測 × 結果 4,750頭（10開催）の実測**

| モデルと市場の関係 | 頭数 | 勝率 | **単勝回収率** |
|------------------|------|------|--------------|
| モデル優位（順位が人気より+5以上） | 350 | 1.4% | **62%** |
| モデル優位（+2〜4） | 1,041 | 2.6% | **48%** |
| 一致（±1） | 2,041 | 9.4% | 77% |
| **市場優位（人気の方が高評価）** | 1,318 | 10.5% | **84%** |

**モデルが「妙味」と判定した馬ほど負ける**というきれいな逆相関。
つまり sc[11] オッズ乖離スコア／V系（妙味馬）／A系（穴軸）は、
**買い目の根拠として使うと損失を拡大させる**。

これは 8/29・8/30 の2日連続全滅の構造的原因でもある（どちらもモデルが
妙味と判定した馬に軸を置いて全額を失った）。

**運用の結論:**
- **V系（妙味馬アンカー）・A系（穴軸）を買い目の主軸に据えない**
- p/q乖離を「買う理由」に使わない。使うなら「市場が評価している馬を確認する」方向に
- 印付けで🔥穴を出すのは可（読み物として）。ただし**買い目の主軸にはしない**
- 「オッズの歪みを見つける」という思想自体は否定しないが、**現在のモデルの
  推定勝率にその歪みを検出する精度がない**というのが実測の結論

### ⭐ v6.1 想定オッズの実配当補正（2026-09-02・確定払戻1,044レースで較正）

```
┌─────────────────────────────────────────────────────────────────────┐
│ Harville式の想定オッズは高配当を系統的に過大評価している。          │
│ 200倍超の3連複は実際には想定の 0.54倍しか付かない。                 │
│ 逆に ◎○▲級の安い3連複は 1.43〜1.53倍と過小評価していた。          │
└─────────────────────────────────────────────────────────────────────┘
```

**実配当 / Harville想定オッズ の中央値（n=1,041レース・想定オッズ帯で層別）**

| 券種 | ~5倍 | 5-15倍 | 15-50倍 | 50-200倍 | 200倍~ |
|------|------|--------|---------|----------|--------|
| 単勝（対照） | 0.99 | 0.99 | 0.99 | 0.99 | — |
| 馬連 | 1.20 | 1.09 | 0.92 | 0.78 | **0.68** |
| ワイド | 1.28 | 1.01 | 0.77 | **0.63** | — |
| 馬単 | 1.13 | 1.12 | 0.99 | 0.87 | **0.70** |
| **3連複** | **1.53** | **1.43** | 1.03 | 0.86 | **0.54** |
| 3連単 | — | 1.23 | 1.27 | 1.06 | **0.74** |

**単勝が全帯で0.99一定**なのが対照実験になっている（市場オッズそのものなので構造上
フラットになるはず）。測定系に配当帯依存の歪みが無いことの証明であり、
他券種の右肩下がりが本物である根拠。

**頑健性3点セット・全通過**
- 期間3分割: 3連複200倍~ は 0.53/0.55/0.54、ワイド50-200倍は 0.66/0.62/0.62
- 上位1%除外: 全項目 ±0.00〜0.02（中央値ベースのため大穴依存ゼロ）
- out-of-sample: train半分から作った係数が 0.55/0.66 と出荷版にほぼ一致

**効果（out-of-sample・valid 380レース / 47,500点）**

| | 較正誤差 | EV>=1.15のROI |
|---|---|---|
| 補正なし | 0.924 | 56.4% |
| 補正あり | **0.804（-13.0%）** | **66.0%（+9.6pt）** |

実装: `payout_correction.py`（後段レイヤー）。`gen_kaime_v5.est_odds()` から呼ぶ。
`ENABLED = False` で従来挙動に即戻せる。実オッズ（--odds-file）を渡している時に最も正確。
係数の更新は `payout_validate.py` を再実行して出力JSONの値を反映する。

```
┌─────────────────────────────────────────────────────────────────────┐
│ 🚨 併せて判明: EV>=1.15 のゲート自体が逆効果の可能性                 │
└─────────────────────────────────────────────────────────────────────┘
```

| 買い方（valid 380レース・フラット賭け） | 点数 | 実測ROI |
|------|------|---------|
| **全候補を機械的に買う（基準線）** | 47,500 | **70.2%** |
| EV>=1.15で絞る（補正なし） | 8,250 | 56.4% |
| EV>=1.15で絞る（補正あり） | 7,595 | 66.0% |

**個々の点をEVで絞ると、全部買うより悪くなる。** EV帯別にも順序性がない
（0.80-1.00帯=0.78 / 1.00-1.15帯=0.27 / 1.40-2.00帯=0.81）。
券種別の基準線: ワイド76.7% > 3連複71.7% > 馬連70.9% > 3連単67.5%

```
│ 🚨 records の一部に結果リーク。原因は backfill_records.py           │
```

### （参考・理論）なぜEV(期待値)が核心とされたか

セミナーで言及された「大衆の感情が作るオッズの歪みをデータで見つける」がアスメシ式の本質。
sc[11]（オッズ乖離スコア）はこの理論の直接実装である。

```
EV = (モデル推定勝率 × 実際のオッズ × 払戻率0.80) - 1

EV > 0  → オッズが過小評価されている（大衆が過度に軽視している）= 買い
EV < 0  → オッズが過大評価されている（大衆が過度に支持している）= 消し
```

### 大衆感情とオッズ歪みのパターン

| 大衆感情 | 現象 | EVへの影響 | 対応 |
|---------|------|-----------|------|
| 過度な人気馬崇拝 | 1番人気のオッズが下がりすぎる | EV大幅マイナス | ✕消し候補 |
| 前走惨敗への過剰反応 | 巻き返し馬が人気を落とす | EV大幅プラス | ◎本命候補 |
| 外枠への先入観 | 外枠馬が不当に嫌われる | EV上昇 | 穴候補 |
| 騎手の知名度 | 無名騎手で馬が過小評価 | EV上昇 | 注目 |
| レース実績のバイアス | 前走G1惨敗→G3で過小評価 | EV上昇 | 買い |

### AIによるEV算出の流れ

```
Step 1: 過去10年（2016〜2026）× 17因子 × 年次重み付けでモデル構築 → 各馬の「真の勝率」を推定
Step 2: 市場オッズ（大衆の感情価格）と比較
Step 3: 乖離 = 歪み = 期待値の機会
Step 4: EV+の馬に淡々と投資
```

## 馬券戦略（回収率300-500%目標）

### 設計思想（v5 EVアダプティブ — 2026-07-31確立）

**核心原則: 「レースごとに46パターンを機械評価し、期待値が最も取れる買い目構成を自動選択する」**

```
旧思想（v4）: 全レース同一の3ブロック構造（馬連中心+3連複）
  → 人気軸レースで配当が薄く300%に届かない
  → 「当たっても微プラス→トータルマイナス」（ガミ）が頻発

新思想（v5）: パターンライブラリ×機械評価×自動選択
  → 人気馬を軸にする時 → 絞る（単勝/馬連/馬単/3連単の1着固定レバレッジ）
  → 人気薄を◎○に据える時 → 広く（ワイド/3連複/馬連で確実に捕まえる）
  → EVが組めないレースは積極的に見送り（0円）
```

### 実行方法（正本スクリプト）

```bash
# 前日（推定オッズで構築）
python src/keiba-predictor/gen_kaime_v5.py \
  --json "Desktop/競馬予想レポート/{日付}/週末ビッグデータ_{日付範囲}_records.json"

# 当日（実オッズで再実行 → 精度大幅向上・必ずやる）
python src/keiba-predictor/gen_kaime_v5.py --json ... --odds-file odds_{日付}.json

# ライブラリ分析（パターン使用分布・限界効用カーブ）
python src/keiba-predictor/gen_kaime_v5.py --json ... --analyze
```

前提: collect_weekend_bigdata.py が出力する records.json（総合指数・ML能力%・自信度算出用データ）

### v5の仕組み

1. **モデル勝率p**: 総合指数の並び順に累積DB実測テーブル（1位34.9%/2位18.2%/3位12.8%…）を割当、ML強度で±25%微調整
2. **大衆勝率q**: 実オッズ優先（0.8/オッズを正規化）。なければ大衆スコア（近走着順40%+ML40%+騎手20%）の並びに同テーブル割当
3. **想定オッズ** = 券種別払戻率 ÷ q（Harville式で馬連・馬単・ワイド・3連複・3連単に展開）
4. **46パターン全てを評価**: 着順シナリオ全列挙で E[回収率]・P(回収率300%+)・的中率・ガミ率を計算
5. **選択基準**: E[回収率]115%以上 × ガミ率35%以下 → P(300%+)最大。基準未満は見送り

**EVの源泉 = モデル順位と大衆順位の「ズレ」**（クオンツのオッズ歪み理論の直接実装）

### 予算（自信度連動）

| 自信度 | 予算 |
|--------|------|
| 10 | 15,000円 |
| 9 | 12,000円 |
| 8 | 8,000円 |
| 7 | 5,000円 |
| 6以下 | 買わない（自信度7以上のみ参加） |

### 評価指標の定義

| 指標 | 意味 |
|------|------|
| E[回収率] | 期待回収率（保守計算: 上位10頭外の決着は回収0扱い） |
| P(300%) | 回収率300%以上を達成する確率 |
| ガミ率 | 的中したのに投資額を下回る確率 ÷ 的中率。**35%以下必須** |

## アスメシ式 週次手動ワークフロー（Claude連携版）

MLスクリプトではなく、ClaudeとWebリサーチを組み合わせた手動予想フローです。
テンプレートスクリプト: `src/keiba-predictor/gen_race_template.py`

### ステップ概要

```
Step 1: 前週PDCA（レース翌日）
  └─ 結果取得 → 予想と照合 → 改善策を策定

Step 2: 今週の予想（レース前日〜当日朝）
  └─ 枠順確認 → 全頭診断 → 予想印・買い目確定

Step 3: SNS投稿案生成（Word）
  └─ gen_race_template.py を書き換えて実行

Step 4: noteヘッダー画像生成
  └─ nanobanana-pro で --attach-image ×2 実行
```

---

### Step 1: 前週PDCA

**Claudeへの指示例:**
```
「昨日のレース結果を分析してPDCAをまわしてください」
```

**Claudeが行うこと:**
- Web検索で1着〜5着・払戻情報を取得
- P(予想) → D(結果) → C(評価) → A(改善策) を出力
- 改善策を次週予想に反映するルールとして整理

**PDCAチェック項目:**
- 本命の根拠は結果と整合していたか
- 前走凡走馬を過信していないか
- 逃げ馬のペース支配を評価していたか
- 騎手乗り替わり馬の扱いは適切だったか

### Step 2: 今週の予想

**Claudeへの指示例:**
```
「今日の予想を行ってください」
「天皇賞春の予想をしてください（条件はいつもの通り）」
```

**Claudeが行うこと:**

2. 全頭診断（AI能力スコア算出）
3. PDCA改善点を反映した予想印（◎○▲△）
4. ペースシナリオ分析（逃げ馬・展開予測）
5. 買い目（単勝・馬連・ワイド・3連複）

**PDCA改善ルール（2026/05/02確定）:**
- 前走凡走馬（着差3馬身超）は印を1段階下げる
- 騎手乗り替わり（3走以内）は信頼度を1段階下げる

- 1400m以下はペースシナリオ必須

### AI指数算出方式（4因子スコアリング）

```
AI指数 (0〜100点) = 追切評価 + 枠順妙味 + 斤量妙味 + コース適性 + 人気期待値

│ 因子           │ 配点  │ 判定基準                              │
│ 追切評価       │ 30点  │ A評価=25〜30, B=15〜24, C=10〜14     │
│ 枠順妙味       │ 20点  │ コース別最適枠=16〜20, 不利枠=5〜8   │
│ 斤量妙味       │ 20点  │ 斤量有利=16〜20, 不利=5〜8           │
│ コース適性     │ 20点  │ 過去同条件勝利・適性◎=16〜20        │
│ 人気期待値(EV) │ 10点  │ EV+（過小評価）=8〜10, EV-=0〜3     │
```

高スコア（80点以上）= 本命〜◎候補
中スコア（60〜79点）= 対抗〜△候補
低スコア（40〜59点）= 注意・消し候補
超低スコア（〜39点）= ×消し

### ライブラリサイズの根拠（2026-07-31実測分析）

```
限界効用カーブ（先頭N種のみ使用時の平均P(300%)）:
   6種 → 13.3%
  24種 → 21.7%
  42種 → 25.7%
  46種 → 25.7%（頭打ち）

結論: 適正規模は約40〜46種。アクティブセット（採用/TOP3実績あり）は26種前後。

```

### 運用ルール

1. **前日**: collect_weekend_bigdata.py → gen_kaime_v5.py（推定オッズで仮構築）
2. **当日朝（必須）**: 実オッズをodds JSONに入れて `--odds-file` で再実行 → 最終確定

3. **レース後**: PDCAでパターン別成績を蓄積 → 採用実績とP300予測の答え合わせ
   - 検証は eval_v5_results_YYYYMMDD.py 方式（実着順×netkeiba払戻で回収率算出）
   - パターン別の実測回収率が貯まったら選択基準（EV_MIN/ガミ率閾値）を再調整

### 🎯 期待値の物差しと「変える／変えない」の判断軸（2026-09-06・dulbea期待値論×自前実測で確立）

出典: dulbea 期待値解説 https://www.dulbea.org/info/keiba-expected-value/
自前の累積DB **14,982頭**で全項目を検証済み。

#### ① 期待値の定義

```
期待値 ＝ オッズ × 的中率
```

1.0が損益分岐。**控除率20%があるので、何も考えずに買えば全帯で0.80前後に収束する。**
0.80から上振れしている帯が「市場の歪み」で、そこだけが買う価値のある領域。

#### ② 人気別の実測（記事の目安と自前実測の照合・14,982頭）

|---|---|---|---|---|---|
| 1 | **35.1%** / 30% | **65.4%** / 60% | 2.5倍 | **0.88** | 過小評価ぎみ |
| 2 | 19.0% / 20% | 52.2% / 50% | 4.2倍 | 0.80 | 理論どおり |
| 3 | 13.3% / 15% | 40.1% / 40% | 6.0倍 | 0.80 | 理論どおり |
| 4 | 10.3% / 10% | 35.9% / 30% | 8.3倍 | **0.85** | 過小評価ぎみ |

| 6 | 4.8% / 5% | 20.7% / 20% | 16.0倍 | 0.77 | 理論どおり |

**読み取れること（自前実測ベース・記事にはない発見）**
- **1番人気の期待値0.88は全人気帯で最良クラス**。記事の目安（勝率30%）より実測は35.1%で強い。
  「1番人気は過剰人気だから消す」は誤り。**軸に据える根拠がある**
- **7番人気が0.68で最悪**。5〜8番人気を「妙味」と呼んで狙うのは、ここが罠
- **4番人気0.85** は1番人気に次ぐ良い帯。**◎×4番人気の組み合わせが構造的に有利**
- 9番人気以下は1.10だが的中率1.1%。分散が大きすぎて単独では使えない（3連複の3頭目向き）

#### ④ 🔑 「変える／変えない」の判断軸

買い目を組んだあと、あるいはオッズが動いたときに、変更するかどうかは次の順で判定する。

```
軸1: 期待値が券種別しきい値を超えているか      → 超えていなければ買わない／外す
軸2: Σ(1/推定配当) ≦ 1.0 を満たすか           → 満たすまで期待値の低い点を落とす
軸3: 乖離の向きはどちらか                      → モデル優位（危険側）なら厚くしない
軸4: 人気帯は良い帯か                          → 7番人気帯（EV0.68）に厚く張らない
```

**変える条件（この時だけ動かす）**

| 事象 | 変えるか | 根拠 |
|---|---|---|
| オッズが動いて期待値がしきい値を割った | **変える**（外す／減額） | 軸1 |
| オッズが動いてΣ(1/配当)が1.0を超えた | **変える**（点を落とす） | 軸2 |
| ◎の実オッズが前日比+50%以上 | **変える**（◎軸依存を解除） | v6.2ガード③ |
| 馬体重±15kg以上 | **変える**（減点。ただし単独で消さない） | 当日ルール |
| 無印馬が市場3番人気以内に急騰 | **変える**（相手に加える） | 9/6に8/11レースで無印馬が3着内 |

**変えない条件（動かしてはいけない）**

| 事象 | 変えないか | 根拠 |
|---|---|---|
| 人気が下がっただけ | **変えない** | 人気低下は妙味増でもある。9/6紫苑S④を人気後退で消し→12.7倍で1着 |
| 人気が上がっただけ | **変えない**（期待値がしきい値内なら） | 上がっても閾値を割らなければ判断は不変 |
| 予想（印）が当たりそうな気配 | **変えない** | 印と買い目は別レイヤー。印の自信で配分を動かさない |
| 他人の予想が自分と違う | **変えない**（最低保証の付与は別） | 合算v2は印に反映、配分には反映しない |

**判断の順序を固定する理由**: 9/5-9/6の失敗は「気配や人気で動かした／動かさなかった」が原因で、
基準が毎回ぶれていた。**上の軸1〜4以外の理由で買い目を変更してはいけない。**

### ⭐⭐ v7 買い目設計（2026-09-06・パターン固定をやめてシナリオベースへ全面刷新）

```
┌─────────────────────────────────────────────────────────────────────┐
│  53種のパターンから選ぶのをやめる。                                 │
│  「その点が当たったとき、いくら返るか」を起点に組み立てる。         │
│                                                                     │
│      その点の的中時回収率 ＝ 配分比率 × 配当倍率                    │
│      これが 1.0 未満の点＝ガミ点。原則として買わない。              │
└─────────────────────────────────────────────────────────────────────┘
```

**作り直した理由**: 予想（印）は当たっているのに買い目が固定的で、当たってもガミる状態が続いた。
9/6は7レース中6レース的中（85.7%）なのに回収66%。**的中6レースのうち5レースは
「当たっても100%に届かない点」で当たっていた**。パターン選択では構造的に直らない。

#### 🔑 中核の原理：Σ(1 / 推定配当) ≦ 1.0

ある点がガミにならない最低額は `予算 ÷ 推定配当`。買う点すべてでこれを満たすには

```
Σ ( 1 / 推定配当 ) ≦ 1.0
```

が必要。これはブックメーカーのオーバーラウンドが100%以下という条件と同じで、
**この不等式を満たせない点数を買った時点で、どう配分してもどこかが必ずガミになる。**

→ 買い目を組むときは、この不等式が成立するところまで**期待値の低い点から落とす**。
　 成立したら、まず各点に `予算 ÷ 推定配当` を確保し、余りを期待値比で上乗せする。

#### ① 期待値がマイナスなら、配分をどう工夫しても破産確率は1

Busseti-Ryu-Boyd (2016) "Risk-Constrained Kelly Gambling" の定理。
**エッジがマイナスの状態での最適賭け金は「0」**であり、券種選択・分散・点数調整で
延命はできても回避はできない。現在の実測69.8%はこの状態にある。

| 1レースの投資額 | 資金100万円が尽きるまで | 週末36Rなら |

| 10,000円 | 331レース | 9.2週 |
| 20,000円 | 166レース | 4.6週 |
| **27,200円（9/6の実額）** | **122レース** | **3.4週** |

→ **エッジが実証されるまでは、賭け金は「検証コスト」として意図的に小さく置く。**
　 9/6の27,200円は、検証段階の額としては大きすぎた。

#### ② 「バンクロールの1%」は3連単ではケリーの約4倍賭け

ケリー基準の1点あたり適正比率は `f* = (回収率 − 1) ÷ (オッズ − 1)`。

| 想定回収率 | オッズ | フルKelly | 1/4Kelly | 100万円なら |
|---|---|---|---|---|
| 110% | 3倍 | 5.00% | 1.25% | 12,500円 |
| 110% | 10倍 | 1.11% | 0.28% | 2,777円 |
| 110% | 30倍 | 0.35% | 0.086% | 862円 |
| **110%** | **100倍** | **0.10%** | **0.025%** | **252円** |

**エッジが本物(+8.75%)でも、1%を張り続けると1,000R後の資金中央値は半減し、
利益が出る確率は32%まで落ちる**（モンテカルロ20,000軌道）。高配当券種ほど、
エッジがあっても賭け金は小さくしなければならない。

| ケリー分数 | 成長率比 | いつか半減する確率 | 1/4になる確率 |
|---|---|---|---|
| フル(1.0) | 100% | **50.0%** | 25.0% |
| ハーフ(0.5) | 75% | 12.5% | 1.6% |
| **クォーター(0.25)** ← 採用 | 44% | **0.8%** | 0.01% |

Benter・ブラックジャックチームの実務値も1/4〜1/2。**フルケリーは使わない。**

|---|---|
| 480分前（当日朝） | **0.334** |
| 20分前 | **0.992** |

出典: Sugawara & Mori (2025)。**当日朝のオッズは「まだ2/3が決まっていない」状態。**
前日オッズはさらに手前で、推定配当の土台としては相当に弱い。

**もう一つの重要な否定的知見**: Hanyu et al. (2026)・JRA 894,127出走の解析で、
**締切直前5分のオッズ変動は事後的にしか観測できず、「オッズ急落馬を買えば儲かる」は成立しない。**
→ 「直前でオッズが下がった＝勝負気配」を買いの根拠にしない。

**運用への反映**
1. **発走直前オッズで配当推定をやり直す**のが理想。ただしSNS投稿の締切と両立しないため、
   現行は「当日朝の再計算」を維持しつつ、**朝オッズ由来の推定配当には約1/3の情報しか
   入っていないと理解して使う**（推定配当の精度を過信しない）
2. **前日時点の買い目は「暫定」と明示する**。当日朝の再計算を省略しない（チェックリストC・既定）
3. **オッズの動き（急落・急騰）を買い/消しの根拠にしない**
4. 逆に言えば、**朝の段階で市場が非効率なのは事実**なので、朝オッズと最終オッズの
   乖離が大きい条件を自前で測れば、それ自体がエッジになりうる（未着手・次の課題）
