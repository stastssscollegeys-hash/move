## 弱点（次のPDCA38で改善すべきポイント）

### 1. 中京 66.7%（PDCA37で-2.7pt悪化）
- **原因推定**: 多頭数×短距離ペナルティが中京で逆効果の可能性
- 中京は直線が長いため短距離でも差し・追込が届く → 他場と違う傾向
- **要改善**: 多頭数×短距離ペナルティを阪神・中山限定にするか検討

### 2. 東京 64.1%（変化なし）
- 乗り替わりペナルティ-3→-1に緩和(PDCA36)したが改善せず
- **要改善**: 東京の長い直線(525m)を考慮した脚質補正

### 3. 小倉 59.2%（+2.4ptだがまだ最弱）
- PDCA37で改善したが依然として唯一の50%台
- 開催後半の馬場荒れ→外枠有利パターンの検出が不十分

### 4. 3-5人気◎ 58.8%（-2.0pt悪化）
- PDCA37で人気馬ペナルティ追加 → 3-5人気◎の母数が79→102に増加
- 人気馬からスコアを奪って中穴に回した分、中穴の精度が問われる
- **要改善**: 穴馬を◎に据える条件をより厳格化（期待値4.0超のみ等）

### 5. 荒れレース(upset6+) 64.7%（+1.2pt改善だがまだ最大課題）
- 全外れの58%がここ
- upset_scoreに「クラス」「開催日程位置」を追加する余地あり

## PDCA履歴

### PDCA37（実装・フル検証完了）
- **実装内容**:
  **model.py**:
  1. 阪神ダート短距離(1200-1400m)×多頭数(13+)で1-2人気に-3（揉まれリスク補正）
  2. 多頭数(15+)×短距離(~1400m)の1番人気に追加-2（展開読み困難）
  3. G1レース(grade='A')の1番人気に+4（G1は能力差明確、中穴狙い裏目防止）
  4. 阪神の堅いレース(upset0-2)で1番人気に-1（阪神は直線短く紛れが起きやすい）
  **pipeline.py / bulk_pdca.py**:
  5. race_gradeをfeaturesに渡すよう追加
  6. race_surfaceの定義位置を前方に移動（UnboundLocalError修正）
  7. num_horsesの定義をループ冒頭に移動（同上）
- **検証結果**: 69.1% → **69.7%**（+0.6pt, 894R: 1/4〜4/5）
- **効果（PDCA36比）**:
  - 荒れ(6+): 63.5% → **64.7%** (+1.2pt)
  - 1-2人気◎: 71.4% → **72.7%** (+1.3pt)
  - 短距離: 65.5% → **66.5%** (+1.0pt)
  - 小倉: 56.8% → **59.2%** (+2.4pt)
  - 大阪杯G1: ◎がショウヘイ(4人気)→クロワデュノール(1人気)に改善
- **悪化箇所**:
  - 中京: 69.4% → 66.7% (-2.7pt) ← 多頭数×短距離ペナルティが中京で逆効果
  - 3-5人気◎: 60.8% → 58.8% (-2.0pt) ← 母数が79→102に増加（人気馬ペナルティで3-5人気◎が増えた）
- **4/5反省ポイント**:
  - 阪神45.5%の壊滅は「1番人気が5/12勝なのに中穴を◎にした」が原因
  - 買い目の回収率は10.8%（厳選4レース×2000円=8000円投資で860円回収）
  - 期待値戦略の中穴狙いが阪神で裏目に出た

### PDCA36（実装済み）
- **実装内容**: 重賞レースの人気馬割引、乗り替わりペナルティ-3→-1に緩和
- **効果**: 69.1%（894R: 4/5含む）

### PDCA35（実装済み・フル検証待ち）
- **実装内容**:
  **difficulty.py（荒れ度判定の改善）**:
  1. 夏開催の月を7-9月→6-8月に拡大（統計: 4月万馬券率1.28%最高）
  2. 古馬OPクラスの荒れやすさ追加（三連単平均246,870円）
  3. 3勝クラスの荒れやすさ追加（到達率9.5%→実力拮抗）
  4. 降級制度廃止フラグ（2019年〜条件戦+32%難化）
  5. 函館を荒れやすい競馬場に追加（洋芝+小回り+夏）
  6. judgeにハンデ戦チェック追加
  **model.py（スコアリングの改善）**:
  7. 少頭数(8頭以下)で1番人気に+5 / 多頭数(16+)で1-3人気に-2
  8. 長距離(2400m+)の1-2番人気に+3（勝率37%超）
  9. 芝中距離(1900-2100m)の1番人気に-2（回収率73.9%最低）
  10. 乗り替わりペナルティ-3（継続8.3% vs 乗替5.4%）
  11. 距離短縮ボーナス+2 / 距離延長ペナルティ-1
- **リサーチ根拠**: 30年間（1996-2025）のJRAデータ分析（8レポート・231KB）
- **期待効果**: 荒れレース的中率61.2%の改善、少頭数/長距離の的中率向上

## PDCAの進め方

1. **このファイルの弱点セクションを読む**
2. **弱点に対してmega-researchでリサーチ**
3. **model.py / pipeline.py に改善を実装**
4. **bulk_pdca.pyで全期間検証**
5. **結果をこのファイルに記録**
6. **検証範囲を過去に拡大（未検証範囲を消化）**
7. **1-6を繰り返す**
