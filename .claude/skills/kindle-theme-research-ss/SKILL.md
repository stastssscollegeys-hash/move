# Kindle漫画テーマリサーチ

## 概要

「漫画でわかる○○」系Kindle本の量産テーマを発掘するリサーチスキル。

```
┌─────────────────────────────────────────────────────────────┐
│                Kindle漫画テーマリサーチ                       │
│                                                             │
│  YouTube需要  ×  Kindle競合  ×  著作権判定  =  推奨テーマ    │
│                                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                   │
│  │ Phase 1  │→│ Phase 2  │→│ Phase 3  │                   │
│  │ YouTube  │  │ Kindle   │  │ 著作権   │                   │
│  │ 需要調査 │  │ 競合調査 │  │ 判定     │                   │
│  └──────────┘  └──────────┘  └──────────┘                   │
│       ↓              ↓              ↓                       │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                   │
│  │ Phase 4  │→│ Phase 5  │→│ Phase 6  │                   │
│  │ 海外発掘 │  │ 書籍動向 │  │ 統合     │                   │
│  │ (deep)   │  │ (deep)   │  │ ランキング│                   │
│  └──────────┘  └──────────┘  └──────────┘                   │
└─────────────────────────────────────────────────────────────┘
```

### 何ができるか

- **YouTube教養チャンネルのトレンド分析**: 再生数が高いのに漫画化されていないテーマを発見
- **Kindle競合チェック**: テーマごとに既存の漫画版があるかを精査
- **著作権リスク自動判定**: 安全/要注意/危険を自動分類
- **海外教育YouTubeからの輸入テーマ発掘**: 日本未到達の需要テーマを発見（deepモード）
- **書籍ベストセラー連動**: 新書大賞・本屋大賞等のトレンドを反映（deepモード）
- **ランク付き推奨リスト出力**: SS/S/A/Bランクで即座に判断可能

## 使い方

```bash
# 基本（全ジャンル・quickモード）
/kindle-theme-research-ss

# ジャンル指定
/kindle-theme-research-ss 哲学
/kindle-theme-research-ss 歴史
/kindle-theme-research-ss 科学

# deepモード（海外YouTube + 書籍トレンドも含む完全版）
/kindle-theme-research-ss --mode deep

# フォーカス指定（特定ソースに集中）
/kindle-theme-research-ss --focus youtube
/kindle-theme-research-ss --focus books
/kindle-theme-research-ss --focus overseas

# 複合
/kindle-theme-research-ss 心理学 --mode deep
```

## 引数

| 引数 | 必須 | デフォルト | 説明 |
|------|------|-----------|------|
| テーマジャンル | いいえ | 全ジャンル | 哲学/歴史/科学/心理学/経済/宗教 等 |
| `--mode` | いいえ | `quick` | `quick`: Phase1-3のみ（5分）、`deep`: Phase1-6全実行（15分） |
| `--focus` | いいえ | `all` | `youtube`/`books`/`overseas`/`all` |

## 実行フロー

### Phase 1: YouTube需要調査（必須）

**目的**: 教養系YouTubeで再生数が高いテーマを抽出

**手順**:
1. 以下のカテゴリからチャンネルを横断検索:
   - 漫画動画系（フェルミ研究所、ぴよぴーよ速報等）
   - 歴史系（ヒューマンバグ大学、非株式会社いつかやる等）
   - 哲学・思想系（中田敦彦YouTube大学等）
   - 科学系（るーいのゆっくり科学等）
   - 経済・ビジネス系（リベラルアーツ大学等）
   - 心理学系（精神科医・益田裕介等）
   - 宗教・神話系（大愚和尚、むすび大学等）

2. 各チャンネルで再生数上位の動画テーマを抽出

3. テーマごとに「需要スコア」を算出:
   ```
   需要スコア = (再生数 ÷ 登録者数) × チャンネル数補正
   - 複数チャンネルで扱われている = 需要大
   - バズ比率（再生÷登録者）が高い = 潜在需要大
   ```

4. WebSearch クエリ例:
   ```
   "{チャンネル名}" site:youtube.com 人気動画
   "{テーマ}" 教養 YouTube 再生数
   "{テーマ}" ゆっくり解説 再生数
   ```

**並列制限**: WebSearch 最大3件/バッチ。3件超の場合はサブエージェントに委譲。

**出力**: テーマ × 需要スコア のリスト（20-30テーマ）

### Phase 2: Kindle競合調査（必須）

**目的**: 各テーマの漫画版Kindle本の有無をチェック

**手順**:
1. Phase 1 で抽出したテーマごとに検索:
   ```
   "{テーマ}" 漫画でわかる Kindle
   "{テーマ}" マンガ 入門 電子書籍
   "まんがで読破" "{テーマ}"
   "{テーマ}" コミック版
   ```

2. 競合状況を3段階で判定:
   | 判定 | 基準 |
   |------|------|
   | **空白** | 漫画版なし（最大チャンス） |
   | **少ない** | 1-2冊のみ（差別化で勝負可能） |
   | **激戦** | 3冊以上（避けるか差別化必須） |

3. 「まんがで読破」シリーズは特に注意してチェック（哲学・古典に多い）

**並列制限**: テーマ3件ずつバッチ検索。サブエージェント使用推奨。

**出力**: テーマ × 競合状況 のリスト

### Phase 3: 著作権判定（必須）

**目的**: 各テーマの著作権リスクを自動判定

**判定基準**:

| 判定 | 条件 | 例 |
|------|------|-----|
| **安全** | 歴史的事実、古代文献（PD）、学術概念、著者没後80年超 | 認知バイアス、暗号の歴史、ストア哲学 |
| **要注意** | 著者没後70年未満だが思想解説はOK。原著の表現・構成は使えない | サルトル（1980年没）、ハンナ・アーレント（1975年没） |
| **危険** | 現代著作物そのものの漫画化。独自構成でないと侵害リスク | 「なぜ働くと本が読めなくなるのか」（2024年刊） |

**自動判定ロジック**:
```
IF テーマが歴史的事実 OR 学術概念 → 安全
IF テーマが古代文献（宗教経典、神話等） → 安全
IF 著者が特定でき、没後80年超 → 安全
IF 著者が特定でき、没後70-80年 → 安全（戦時加算注意）
IF 著者が特定でき、没後70年未満 → 要注意
IF 現代書籍がベース → 危険
```

**追加チェック**:
- KDP（Amazon）ガイドライン: 宗教批判・政治偏向がないか
- 宗教テーマ: 客観的・学術的な解説であることを確認
- AI生成申告: 必要な場合の注記を追加

**出力**: テーマ × 著作権判定 × 対策メモ

### Phase 4: 海外教育YouTube発掘（deepモードのみ）

**目的**: 英語圏で人気だが日本に来ていないテーマを発見

**対象チャンネル**:
- Kurzgesagt（科学・哲学、2300万人）
- OverSimplified（歴史、870万人）
- TED-Ed（教育、1900万人）
- Crash Course（全般、1500万人）
- Veritasium（科学、1600万人）
- 3Blue1Brown（数学、600万人）
- Exurb1a（哲学、300万人）
- Kings and Generals（軍事史、400万人）
- Academy of Ideas（哲学、100万人）
- After Skool（哲学アニメ、200万人）
- Daily Stoic（ストア哲学、200万人）

**手順**:
1. 各チャンネルの人気動画テーマを検索
2. 日本語で同テーマのYouTube・漫画があるかチェック
3. 「日本未到達度」を判定:
   - 完全空白: 概念すら知られていない
   - ほぼ空白: Wikipedia程度
   - 部分的: 学術書のみ

**出力**: 海外テーマ × 日本未到達度 × 漫画化適性

### Phase 5: 書籍トレンド発掘（deepモードのみ）

**目的**: ベストセラー・受賞作品からトレンドテーマを発見

**調査対象**:
- 新書大賞（直近3年）
- 本屋大賞ノンフィクション部門
- Amazonベストセラー（教養・ノンフィクション）
- SNSで話題の書籍（X、note、はてなブックマーク）
- Google検索トレンド（教養系キーワード）

**手順**:
1. 受賞・ベストセラー書籍のテーマを抽出
2. そのテーマの漫画版があるかチェック
3. YouTube上の解説動画の有無を確認
4. 空白度を判定（漫画もYouTubeもない = 空白度S）

**出力**: 書籍テーマ × 空白度 × 漫画化適性

### Phase 6: 統合ランキング生成（必須）

**目的**: 全フェーズの結果を統合し、最終推奨ランキングを作成

**スコアリング**:
```
最終スコア = 需要スコア(30%) + 空白度(30%) + 著作権安全度(20%) + 漫画化適性(20%)

需要スコア: YouTube再生数・チャンネル数・書籍売上から算出
空白度:     漫画版なし=100, 1-2冊=50, 3冊以上=0
著作権安全度: 安全=100, 要注意=50, 危険=0
漫画化適性:  最高=100, 高=75, 中=50, 低=25
```

**ランク分け**:
| ランク | 基準 | 意味 |
|--------|------|------|
| **SS** | スコア85以上 + 著作権安全 | 即着手推奨 |
| **S** | スコア70以上 | 空白大×需要あり |
| **A** | スコア55以上 | 高チャンス |
| **B** | スコア40以上 | 差別化次第で参入可能 |

**出力ファイル構成**:
```
output/kindle-theme-research/
├── 00_summary.md              # 統合レポート（このファイルだけ見ればOK）
│                               # - 全テーマランキング（著作権カラム付き）
│                               # - 著作権クイックガイド
│                               # - 量産戦略の提案
│                               # - 裏付けデータへのリンク
├── 01_kindle_competition.md   # Kindle競合チェック詳細
├── 02_youtube_themes.md       # YouTube需要分析詳細
├── 03_copyright_guide.md      # 著作権判定ガイド
├── 04_youtube_channels_full.md # チャンネル完全リスト（deepのみ）
├── 05_overseas_themes.md      # 海外テーマ（deepのみ）
└── 06_blank_themes_from_books.md # 書籍トレンドテーマ（deepのみ）
```

## サブエージェント構成

リサーチは3つのサブエージェントに委譲して並列実行する:

```
メインプロセス
├── Agent 1: YouTube需要 + Kindle競合（Phase 1-2）
├── Agent 2: 著作権判定 + 海外テーマ発掘（Phase 3-4）
└── Agent 3: 書籍トレンド + SNSトレンド（Phase 5）
        ↓
メインプロセス: Phase 6 統合ランキング生成
```

各エージェント内のWebSearch/WebFetchは最大3件/バッチ（research-delegation.md準拠）。

## ベストプラクティス

### 効果的な使い方

1. **初回は `--mode deep` で全体像を掴む**
   - 全ソースからテーマを網羅的に発掘
   - 15分程度かかるが、最も正確

2. **2回目以降は `--mode quick` で差分更新**
   - YouTube + Kindle + 著作権のみ（5分）
   - トレンド変化のキャッチアップに

3. **ジャンル指定で深掘り**
   - 「哲学」「歴史」等を指定すると、そのジャンルを重点調査
   - Phase 1のチャンネル選択が最適化される

### 注意事項

- **YouTube再生数は変動する**: 調査時点の数値。定期的に再実行推奨
- **Kindle競合は新刊で変わる**: 月1回程度の再チェック推奨
- **著作権判定は目安**: 実際の出版前に法的確認を推奨
- **「安全」でも翻訳書の表現コピーはNG**: 一次資料から独自に書く
