# YouTube Research SS - 動画リサーチ＆バズ検知スキル

## Overview

YouTube動画のデータを受け取り、以下を一気通貫で分析するスキル:

1. **バズ検知** - 登録者数に対して再生数が異常に多い動画を発見
2. **トレンド判定** - 今その動画のテーマで出しても間に合うかを判定
3. **ターゲット層分析** - どんな視聴者がこの動画を見ているか推定
4. **キーワード抽出** - SEO/YouTube SEO向けキーワードを分類・抽出
5. **勝ちパターン提案** - バズ要因を分析し、再現可能なパターンを提案

## When to Use

```
「YouTube動画を分析して」
「バズ動画を見つけて」
```

## Full Workflow（7フェーズ）

### Phase 1: データ入力・整理

ユーザーから動画データを受け取る。以下のいずれかの形式を受け付ける:

- **YouTube URL**（1本〜複数本）
- **文字起こしテキスト**（ファイルパス or 直接貼り付け）
- **動画の要約テキスト**

**ユーザーへのヒアリング:**

```
以下を教えてください:

1. 動画データ（以下のいずれか、複数可）:
   - YouTube URL
   - 文字起こしテキスト
   - 動画の要約

2. フィルタ条件（任意）:
   - キーワード/ジャンル:
   - 動画の長さ: [ショート / ミディアム / ロング / すべて]
   - 投稿期間: [1週間 / 1ヶ月 / 3ヶ月 / 1年 / すべて]

3. 分析の目的（任意）:
   例: 「自分のチャンネル企画のため」「競合分析」「市場調査」
```

複数動画がある場合、`---` で区切るか URL を1行ずつ入力。

### Phase 2: メタデータ取得

各動画からメタデータを収集する:

**URLが提供された場合:**
- WebFetchで YouTube ページにアクセス
- 取得する情報: タイトル、説明文、チャンネル名、再生回数、高評価数、コメント数、投稿日
- チャンネルページから推定登録者数を取得

**文字起こし/要約が提供された場合:**
- テキストをそのまま保持
- メタデータが不足する場合はユーザーに補足を依頼（再生数・登録者数など）

**出力フォーマット（動画ごと）:**

```markdown
### 動画 #1
- タイトル: {title}
- チャンネル: {channel}（登録者 約{subscribers}人）
- 再生数: {views}
- 投稿日: {date}
- 長さ: {duration}
- 説明文: {description_summary}
```

### Phase 3: バズ検知

**核心ロジック: 登録者少ない × 再生数多い = バズ動画**

各動画のバズ比率を算出:

```
バズ比率 = 再生数 ÷ 登録者数
```

| バズ比率 | 判定 |
|---------|------|
| 10以上 | 超バズ（登録者の10倍以上の再生） |
| 5〜10 | バズ（登録者の5〜10倍） |
| 2〜5 | 好調（登録者の2〜5倍） |
| 1〜2 | 平均的 |
| 1未満 | 低調 |

**バズ比率が高い順にランキングを作成。**

次に、バズ動画に共通する要因をAIで分析:

```
以下のバズ動画に共通するパターンを分析してください:

{バズ動画のタイトル・説明文・キーワード一覧}

分析観点:
1. タイトルの共通パターン（数字、疑問形、煽り等）
2. トピックの共通テーマ
3. 投稿タイミング（曜日、時間帯、時事ネタとの関連）
4. サムネイル要素の推測（タイトルから推測できる視覚要素）
5. 動画の長さの傾向
```

### Phase 4: トレンド判定（今出しても間に合うか）

バズ動画から抽出したキーワードに対し、3つの観点でチェック:

**1. Google Trends チェック**
- WebSearchで「{keyword} Google Trends」を検索
- または WebFetchで Google Trends ページにアクセス
- 上昇傾向↑ / 横ばい→ / 下降傾向↓ を判定

**2. YouTube検索トレンド**
- WebSearchで「{keyword} site:youtube.com」を検索
- 直近の動画投稿頻度を確認
- 上昇傾向↑ / 横ばい→ / 下降傾向↓ を判定

**3. 競合チャンネル数**
- 同キーワードで動画を出しているチャンネル数を推定
- 少ない○ / 普通△ / 多い× を判定

**総合判定:**

| Google Trends | YouTube検索 | 競合度 | 判定 |
|--------------|------------|--------|------|
| ↑ | ↑ | 少○ | 今すぐ出すべき！ |
| ↑ | ↑ | 多× | チャンスだが競争激しい |
| ↑ | → | 少○ | 先行者優位を取れる |
| → | → | 少○ | ニッチで安定的に狙える |
| ↓ | ↓ | - | タイミング遅い、別テーマ推奨 |

**注意:** WebSearchは3件ずつバッチ処理（research-delegation.mdのルールに従う）。
4+キーワードの場合はTaskサブエージェントに委譲。

### Phase 5: ターゲットオーディエンス分析

動画コンテンツ全体をAIで分析:

```
以下のYouTube動画コンテンツを分析し、ターゲットオーディエンスを推定してください。

## 動画データ
{全動画のメタデータ + 文字起こし/要約}

## 分析観点
1. デモグラフィック（年齢層、性別、職業/ステータス）
2. サイコグラフィック（興味関心、価値観、ライフスタイル）
3. 課題・悩み（この動画を見る人が解決したい問題）
4. 視聴動機（なぜこの動画を見るのか）
5. 購買行動パターン（何を買いそうか、どんなサービスに興味があるか）
6. 類似コンテンツ（他にどんなチャンネル/メディアを見ているか）

## 出力フォーマット
各項目について根拠（動画のどの部分から推定したか）を明記。
複数動画がある場合は共通ターゲットと動画固有ターゲットを分けて記述。
```

4本以上の動画がある場合はTaskサブエージェントで並列分析。

### Phase 6: キーワード抽出・分類

```
以下のYouTube動画コンテンツからキーワードを抽出・分類してください。

## 動画データ
{全動画のメタデータ + 文字起こし/要約}

## キーワード分類
1. メインキーワード（動画の主題を表す1〜3語）
2. サブキーワード（動画内で繰り返し出現するトピック）
3. ロングテールキーワード（3語以上の具体的フレーズ）
4. 関連キーワード（直接登場しないが関連する検索語）
5. 購買意図キーワード（「おすすめ」「比較」「買い方」等）
6. 質問キーワード（「〜とは」「〜方法」「〜なぜ」等）
7. トレンドキーワード（時事性のある用語）

## 各キーワードに付与する情報
- 推定検索ボリューム感: 高/中/低
- 競合度感: 高/中/低
- コンテンツ適合度: 高/中/低
- 用途提案: YouTube SEO / ブログ記事 / SNS投稿 / 広告

## 出力
テーブル形式で出力。
```

### Phase 7: レポート生成

**出力先:** `output/youtube-research-{slug}/`

## Error Handling

| エラー | 対処 |
|--------|------|
| URLからメタデータ取得失敗 | ユーザーに手動入力を依頼 |
| 再生数/登録者数が不明 | バズ検知をスキップ、他のフェーズは実行 |
| WebSearch失敗 | リトライ1回、それでも失敗なら当該キーワードスキップ |
| 動画が1本のみ | バズ比較はスキップ、単体分析のみ実行 |
