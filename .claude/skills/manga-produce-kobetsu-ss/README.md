# manga-produce-kobetsu-ss

電子書籍を漫画化することに特化したスキル（キャラ個別シート版）。

## 特徴

- **章ベースで漫画化**: 書籍の各章を独立した漫画シーンとして構成
- **各章3-5ページ**: 全5章なら15-25ページの漫画が完成
- **キャラ個別シート**: キャラ1人=1枚の個別シート画像（ファイル名はカタカナ名）
- **重要ポイント抽出**: 章の主旨が伝わる部分を優先、細部は省略OK
- **対話形式**: 主人公（学ぶ役）と先生（解説役）の会話で展開

## manga-produce-creator-ss との違い

- キャラシートが全員1枚 → **キャラ1人=1枚の個別シート**
- 各ページの画像生成時に登場キャラの個別シートのみを添付

## 使用方法

```
「書籍を漫画化して（個別キャラシートで）」
「この電子書籍を漫画化して」
```

詳細は `SKILL.md` を参照。
