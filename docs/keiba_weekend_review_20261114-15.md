## 3. 的中率を上げる方法の検証（10年・25,440レース・年ごとの前向き予測×確定払戻）

### ◎の付け方（`mark_rule_test.py`・11/14）
| ◎ | 勝率 | 3着内 | 単勝回収（前半・後半） |
|---|---|---|---|
| 現行（勝つ確率8%以上で最も割安） | 22.9% | 51.4% | 91.4%（92・91） |
| 下限12% | 26.5% | 56.4% | 89.5%（89・90） |
| モデル確率1位 | 33.5% | 64.9% | 81.5%（82・81） |
→ 当たる頻度を上げると回収率は下がる（人気馬は配当が見合わない）。

### 買い目の軸（`axis_structure_test.py`・11/16 新設）
P＝モデル確率1位（一番来そうな馬）。印（割安さ順）は変えず、買い目の軸だけを変える。1点100円の均等買い。
Pと◎が同じ馬のレースは 33.5%。3着内は P 64.9%・◎ 51.4%・**どちらかが来る 77.0%**。

| 形 | 点/R | 何か当たる | 回収（前半・後半） |
|---|---|---|---|
| ワイド ◎流し（現行） | 3.3 | 44.5% | 88.7%（89.3・87.9） |
| ワイド P流し | 3.3 | 55.1% | 83.3%（83.7・82.9） |
| **ワイド 二軸（◎流し＋P流し）** | 4.8 | **64.1%** | 85.7%（86.4・85.0） |
| ワイド P-◎の1点 | 1.0 | 24.8% | 86.0% |
| 馬連 ◎流し | 3.3 | 26.3% | 89.3%（89.6・89.0） |
| 馬連 P流し | 3.3 | 33.8% | 83.3% |
| 3連複 ◎1頭軸流し | 4.0 | 17.6% | 87.9% |
| 3連複 P・◎の2頭軸流し | 2.4 | 13.2% | 85.9% |

- **どの形でも回収率は上がらない**（これまでの結論と同じ）。軸をPに寄せるほど当たる頻度は上がり、回収率は3〜5ポイント下がる。
- **二軸（◎流し＋P流し）は、何か当たるレースが 44.5%→64.1% に増え、回収率の低下は約3ポイント**。前半・後半とも同じ向き。「軸が外れたら全滅」を減らす形として一番効く。

## 4. 変えること（SKILL に反映）

0. （2026-11-16 ユーザー決定）**二軸は標準にしない。場合によって検討する**。下の1は「検討する形」として残す。あわせて「1日または土日2日の合計で回収率100%超をねらい、その日の収支を見て後半のレースを組む」を SKILL §2 に追加した（金額は増やさない・券種と組み合わせで届かせる）。
1. **買い目に「一番来そうな馬（モデル確率1位＝P）」を入れる形（二軸）を、場合によって使う**。Pと◎が別の馬のレース（約3分の2）は、◎の流しに加えて P からの流し（または P-◎・P-○）を入れる＝二軸。
   ねらいは当たる頻度（44.5%→64.1%）。回収率は約3ポイント下がる見込みなので、投稿には「当たる頻度を上げるための形」と書き、回収率が上がるとは書かない。
2. **保険は金額で効かせる**。軸が飛んだときに戻りが出る点（Pからの流し・印同士）に、買い目全体の3割以上を配る。100〜500円の保険は付けない。
3. **「最長」「ゼロ」は定義を確かめてから書く**（race_profile の表示は修正済み）。
4. 印の付け方（割安さ順）と独自指数の配点（近走40・型20・適性20・脚質10・状態10、オッズに混ぜる強さ0.1＝11/14 に測り直し済み）は変えない。
   今週末で指数を新しく採点できたのは重賞3レースだけで、配点を動かす根拠にならない。
