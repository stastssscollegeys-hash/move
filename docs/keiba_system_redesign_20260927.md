## 5b. 文脈層（同日追加・ユーザー指示「レース自体・その日・前日・トラックバイアスも加味」）

`context_layer.py` で4層に分け、`context_audit.py` で「同じ人気帯の中で層が有利とした馬が走るか」を全件で検定。

| 層 | 結果（1,888R・19,872頭・想定脚質＝DB直近5走多数決） |
|---|---|
| L1 コース実測（距離帯×馬場の脚質別） | 差なし（-0.19pt） |
| L2 当日（同日同場の終わったレース） | +0.47pt z=+0.92 |
| L3 前日（同場直前開催） | +0.83pt z=+1.64（後半で消える） |
| L2+L3 | 474Rで z=+2.96 通過 → 1,888Rで z=+1.41 に消えた＝偶然 |

**結論: 当日・前日の傾向は市場が織り込んでいる。** `db/context_layers.json` の enabled は空のまま。
文脈は `describe(ctx)` でSNSの説明文（実測値）に使い、確率には掛けない。監査を通った層が出たら json に書くだけで `kaime_core` が掛ける。
途中で判明: レース前recordsの脚質は実際との一致率27.6%（偶然25%）で壊れていた → `ContextDB.style_forecast()`（41.9%）に置換。
蓄積DBの脚質は結果（コーナー通過由来）なので、脚質の検定に使うと z=+15 の偽陽性が出る。
