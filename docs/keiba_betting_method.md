# 買い目の作り方（期待値で選ぶ方式）— 2026-10-14 時点の記録

目的は**年間を通した回収率100%超（当面120%）**。的中率ではなく回収率で判断する。
この文書は「どうやって買う馬券を決めるか」と「その方法をどう確かめているか」の正本の控え。
手順書 `SKILL.md`（v5.1）の §0・§1・§5 と合わせて読む（下の「SKILL.md への追記案」をそのまま貼れる）。

## 1. 考え方（ビル・ベンターと同じ）

1. **市場（単勝オッズ）を土台にする。** 何万人分の予想を平均した数字なので、単独の予想より強い
2. **自分の計算で少しだけ補正する。** `ev_engine.py`: 馬の強さ = β×ln(市場の確率) ＋ Σ 重み×特徴量（調教・前走・間隔・馬体重・騎手/厩舎/種牡馬の「市場より勝つ度合い」など）
3. **市場と見立てがずれた所だけ買う。** 全部のレースで買うと手数料（単勝20%・3連単27.5%）にそのまま負ける
4. **組み合わせの確率は λ-Harville**（2着 p^0.80・3着 p^0.70）。素朴な掛け算は上位の組を10〜30%高く見積もる

## 2. 選び方のルール（現在の候補）

## 3. 確かめ方（後付けの当たりを避ける）

- **年ごとの前向き検証**: その年より前だけで学習 → その年を予測（`strategy_tournament.py --build`）
- **発見と確認を分ける**: 2019〜2023 で候補を選び、2024〜 で同じ条件のまま確かめる。選ぶ段階で多重比較の補正（Benjamini-Hochberg）
- **事前登録**: 条件を固定して `daily_pdca/db/strategy_registry.json` に登録し、登録日より後のレースだけで判定（報告の §4）
- 実戦の台帳（`ev_live.py`）: U1.0 → `ledger_u1.json`、E2.1 → `ev_ledger.json`、単勝 T1 → `ev_ledger_tan.json`

## 4. これまでに分かった落とし穴

| 落とし穴 | 実例 |
|---|---|
| 条件を後から探すと必ず「当たり」が見つかる | 単勝3〜6倍（T1）: 発見126% → 確認98% ／ 3連単λ期待値: 130% → 99% |
| 良い時期だけ切り取る | 馬連U1の「3年で117.3%・下限101.8%」は 2023〜の好調期。8年では108.9%・下限97% |
| 推定配当の誤差は利幅より大きい | 期待値1.2以上に絞ると全券種崩れる（推定配当の誤差±25〜35%）。3連系は実際の発売オッズが無いと判断できない |
| 天気・前日の偏り・文脈情報は市場に織り込み済み | 確率が改善しない（対数尤度ほぼ不変） |
| 元データの「脚質」は定義が違う | 最初のコーナー2番手以内を全部「逃げ」にしている（1レースに2〜3頭）。コーナー通過順から付け直す（`course_profile.style_of`） |

## 5. 予想での使い方（毎週）

1. 当日朝: `ev_live.py` が全レースを計算 → 候補の買い目が出たレースが「期待値の取れるレース」（Wordの上に並べる）
2. 型の確認: `python course_profile.py --course 京都芝2000m` / `--race 秋華賞` でコース・重賞の型カードを引く（勝ち馬の人気・枠・脚質・ペース・今年の傾向）。**型カードは読み・説明用で、確率の入力ではない**
3. 結果が入ったら: `strategy_tournament.py --build` → `strategy_tournament.py` で事前登録の成績（§4）を更新。月1回で十分

## 6. 次に調べること

1. 買う時刻: 発走35分前のオッズと確定オッズのずれ（台帳の odds_now と確定オッズ）
2. 当日にしか出ない情報: 当日の馬体重の変化・乗り替わりの理由
3. 資金配分: 均等 vs ケリー（C1 と C6 の比較）
4. 3連系: 実際の発売オッズを全レース記録し、λ期待値を実オッズで判定し直す
