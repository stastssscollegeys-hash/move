## 3. 国内MAツール比較

### ツール別特徴

#### エキスパ（Expa）
- **種別**: オールインワン（メール+LINE+SMS）
- **特徴**: トリプル配信（メール・LINE・SMS）、ウェビナー、決済代行、サイト作成（100テンプレ）、ファネル構築、アフィリエイト
- **料金**: 月額0円〜16,170円

#### エルメ（L Message）
- **種別**: LINE特化
- **特徴**: 無料プランが充実、Googleカレンダー連動予約、フォーム・LP作成
- **料金**: 無料（1,000通/月）〜 10,780円（無制限）

#### MyASP（マイスピー）
- **種別**: メール配信中心オールインワン
- **特徴**: リスト数・シナリオ数無制限、決済連携、アフィリエイト、会員サイト
- **料金**: 月額3,300円〜

#### プロラインフリー
- **種別**: LINE特化
- **特徴**: 無料でメッセージ配信無制限、決済・予約・LP・アフィリエイト全機能利用可
- **料金**: 無料〜29,700円

#### Liny
- **種別**: LINE特化（高セキュリティ）
- **特徴**: Pマーク取得、官公庁・金融機関導入実績、二要素認証
- **料金**: 要問合せ

#### かんたんラインステップ
- **種別**: LINE特化（初心者向け）
- **特徴**: 直感的UI、Zoom連携、流入経路自動判別
- **料金**: リーズナブル

## 4. 海外MAツール調査

### 主要ツール比較

#### ClickFunnels 2.0
- **コンセプト**: ファネル特化オールインワン
- **主要機能**: ファネルビルダー、メールMA、会員サイト、オンラインコース、コミュニティ、Smart Checkout（オーダーバンプ/アップセル/ダウンセル）、Backpack（アフィリエイト）、A/Bテスト、CRM、ワークフロー、Payments AI
- **料金**: $81〜$297/月（年払い）

#### GoHighLevel (GHL)
- **コンセプト**: エージェンシー向けオールインワン
- **主要機能**: CRM、ファネル、メール、SMS、パイプライン、予約管理、レビュー管理、コールトラッキング、WhatsApp連携
- **特徴**: ホワイトラベル・SaaS再販可能
- **料金**: $97〜$497/月

#### Kajabi
- **コンセプト**: デジタルクリエイター向け
- **主要機能**: オンラインコース、コーチング、メンバーシップ、コミュニティ、ニュースレター、ポッドキャスト
- **料金**: $89〜$399/月

#### Kartra
- **コンセプト**: フルスタックMA
- **主要機能**: ページビルダー、メール/SMS、カート、CRM、メンバーシップ、ビデオホスティング、予約管理、ウェビナー（300人）
- **特徴**: 行動ベースの自動マーケティング変更（例：動画75%視聴者 vs 10%で異なるフォロー）、AIコピーライティング
- **料金**: $99〜$429/月（年払い）

#### Systeme.io
- **コンセプト**: 低価格オールインワン
- **主要機能**: LP、メール、コース、ウェビナー、アフィリエイト、ファネル
- **特徴**: 無料プランあり（2,000コンタクト、3ファネル、無制限メール）
- **料金**: 無料〜$97/月

#### ActiveCampaign
- **コンセプト**: メールMA + セールスオートメーション
- **特徴**: 高度なマルチステップオートメーション
- **料金**: $15〜$79/月

#### HubSpot
- **コンセプト**: CRM + MA 総合プラットフォーム
- **特徴**: 無料CRMプランが充実、エンタープライズ向けスケーラビリティ

#### GetResponse
- **コンセプト**: メール + ウェビナー統合
- **特徴**: メールMAとしてはウェビナー機能を内蔵する珍しい構成
- **料金**: $13.3/月〜

### インタラクティブコマース（ウェビナー中の購入機能）

**WebinarJam Active Offers が最も代表的:**
- プレゼンターがボタンを押すと全参加者の画面にオファーがポップアップ
- ポップアップ内リンクからチェックアウトページへ遷移、その場で購入

**EverWebinar Sidebar Offers:**
- カウントダウンタイマー + 在庫カウンター + CTAボタン付きサイドバー
- 自動ウェビナーでの緊急性演出

**Kartra + WebinarJam連携:**
- ライブイベント中にKartraのチェックアウトをポップアップ表示
- 参加者を出席状況でタグ付け → 行動ベースの自動フォローアップ

## 10. 実装ロードマップ

### Phase 1: 基盤構築（MVP）
**目標**: 最小限のファネル → リード獲得 → メール/LINE配信 → 決済

1. Next.js + Supabase でプロジェクト基盤
2. ファネルビルダー（シンプルなLP作成）
3. メール配信（SES + ステップメール）
4. LINE Messaging API連携（ステップ配信）
5. Stripe決済連携
6. 基本的なCRM（顧客管理・タグ）
7. ダッシュボード（基本KPI）

### Phase 2: MA機能拡充
**目標**: 高度な自動化・分析・予約

8. ワークフローエンジン（Temporal）導入
9. セグメント配信（メール・LINE）
10. リッチメニュー出し分け
11. 流入経路分析・クロス分析
12. スコアリング
13. Cal.com統合（予約管理）
14. SMS / WhatsApp配信（Twilio）
15. A/Bテスト

### Phase 3: ウェビナー・会員サイト・AI
**目標**: 高付加価値機能

16. ウェビナー機能（ライブ + 自動）
17. ポップアップオファー（ウェビナー中購入）
18. 会員サイト（コース・レッスン管理）
19. AIチャットボット（Claude Haiku）
20. AIアシスタント（コンテンツ生成）
