## 1. 馬カード（その馬はどんなレースに強いか）

条件ごと（芝ダ・芝ダ×距離帯・競馬場・回り・馬場・頭数・クラス・季節・間隔・ペース・枠・自分の脚質）に着別成績を数え、
**人気から期待される3着内の数と比べる**（人気×頭数帯ごとの全体の3着内率から計算）。差がプラス＝その条件では人気以上に走ってきた。

例: トロヴァトーレ（富士S）＝左回り +2.0・東京 +1.6・スローペース 7戦5勝 +1.6・休み明け（6〜12週）+2.4
　　エンネ（秋華賞）＝芝1700〜2200m 3戦1-2-0-0 +1.9

⚠ 1頭あたりの走数は少ない（2〜10走）ので、差が±1回程度は偶然の範囲。**読み・説明の材料**として使う。

## 2. どんな馬が、どんなレースで走るか（型の分析）

レース前に分かる特徴 × レースの型（芝ダ×距離帯×クラス群）。**比**＝3着内の実数÷人気からの期待（1.00＝人気どおり）。
前半（〜2022）と後半（2023〜）の両方で同じ向き・|z|≧3 のものだけ。**全馬の単勝回収率は72.7%**（これより高い・低いが目安）。

### 全レースで安定していた型

| 特徴 | 比 | 単勝回収率 | 読み |
|---|---:|---:|---|
| 芝ダ変更 | 0.87 | 69% | 人気ほど走らない（モデルに入っている） |
| 前走10着以下 | 0.92 | 68% | 人気ほど走らない |
| 休み明け（13週〜） | 0.93 | 71% | 人気ほど走らない |
| **馬体重 439kg以下** | **0.94** | **56%** | **市場が明らかに買いかぶる**（モデルに無かった） |
| 前走2〜3着・前走の上がり2〜3位 | 1.05 | 74〜75% | 人気以上に走る |
| **同じ芝ダ×距離帯で3着内の経験あり／なし** | **1.03／0.95** | 76／69% | 条件の経験は効く（モデルに無かった） |

### レースの型ごとに目立つもの

| レースの型 | 人気ほど走らない | 人気以上に走る |
|---|---|---|
| 新馬・未勝利（芝・ダ） | 前走10着以下（0.78）・芝ダ変更（0.80〜0.85） | 前走2〜3着・前走の上がり1〜3位（1.09〜1.13） |
| ダ〜1300m・1〜2勝 | **昇級（0.83）・前走1着（0.86）** | 前走で差した馬（1.07） |
| ダ〜1300m・3勝〜重賞 | － | **前走で差した馬（1.17）** |
| ダ1400〜2200m・1〜2勝 | 芝ダ変更（0.84）・**前走で逃げた馬（0.87〜0.90）**・休み明け | － |
| ダ1400〜1600m・新馬未勝利 | 馬体重439kg以下（0.87・単勝回収率37%） | 同じ条件で3着内の経験あり（1.14） |
| 芝1400〜1600m・1〜2勝 | 馬体重439kg以下（0.89・51%） | － |

読み方: ダートの短距離は**勝ち上がった直後の昇級馬が人気ほど走らず**、上のクラスでは前走で差していた馬が来る。
ダートの中距離は**前走で逃げた馬が人気になり過ぎる**。新馬・未勝利は前走の着順と上がりが素直に効く。

### 🔴 確認して見つかった不具合（本体側 v5.1 の `ev_live.py --quick`）

`--quick` は**朝に作った特徴量（`db/ev_cache/{日付}.pkl`）にオッズだけ入れ替える**。朝はまだ馬体重が発表されていないので、
**発走前の本番計算で馬体重の特徴量が空（0）のまま**になっている。今ある「馬体重 増減」「10kg以上減」「10kg以上増」も同じで、
学習では効いているのに本番では使われていない。
- このブランチの `ev_live.py`（`--quick` なし・レースごとに全部計算）は JV速報 0B11 の馬体重を毎回入れているので問題ない
- 直し方: `--quick` で、`load_wh(date)` の馬体重から 馬体重の列（増減・10kg以上減/増・HORSEFIT の2列）を計算し直して X を上書きする
- 本体側のファイルなので、このブランチからは直していない（統合のときに直す）
