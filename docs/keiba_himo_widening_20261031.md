# 3着候補（紐）を広げる検証と、印が前日から消える理由（2026-10-31）

きっかけ: 天皇賞（秋）で、10/30の版で🔥だった④レディネスが前日夜の版で印から消えた。ユーザー指示「消えた理由の根本原因を考える・穴なら紐を広げてよいのでは・3連複も」。

## 1. ④レディネスが消えた根本原因
- 10/29〜30の版は発売前の想定オッズ（netkeiba 10/29 21:15）で計算していた。前日発売が始まった10/31の実オッズで、人気薄の倍率が約2倍になった（④ 23.4→46.7倍、⑯ジョバンニ 14.6→55.6倍、⑩ネブラディスク 15.3→44.1倍）。
- 確率は市場の確率が土台なので、④の勝つ確率は3.5%→1.6%に半減し、割安さの比も1.02→0.96に下がった。🔥の条件は「6番人気以下・勝つ確率2%以上で最も割安」＝2%の足切りを下回って外れた（△の3%も下回る）。
- 入力が変わっただけでエンジンの不具合ではない。**発売前の想定オッズの版は、人気薄の印（🔥・△）を過大に出す**。
- 版が進んだときの割安さの変化（2019以降ではなく10/11〜10/31の7日・約2,000頭）: ~10倍は平均+0.001、10〜30倍は-0.005、30倍〜は-0.017（28%の馬で下がる）。天皇賞は想定→実売の差が大きい例。
- 印が最初の版から最後の版で変わったレースは 41/150（27%）。

## 2. 「消えた馬は来る」は本当か（5週末・印が変わった41レース）
- 印が消えた馬 50頭の3着内は実際9頭、最終オッズから期待される数は6.7頭（差+2.3・標準偏差2.3・z=+1.0）。印が増えた馬は46頭で実際11頭・期待13.4頭（z=-0.84）。向きはユーザーの印象と同じだが、誤差の範囲（母数が足りない）。毎週版を残して累計する。

## 3. 紐を広げる検証（24,927レース・2019〜・実払戻・1レース10,000円・各点同額）
| 戦略 | 回収率［95%区間］ | 何か当たる |
|---|---|---|
| A 3連単マルチ・相手=印の4頭（現行K12） | 97.3%［86.1〜109.7］ | 4.7% |
| B 相手=勝つ確率上位4頭 | 91.4%［83.7〜99.8］ | 5.5% |
| C 相手=勝つ確率上位6頭 | 91.1%［83.6〜98.8］ | 6.6% |
| D 相手=印4頭＋確率上位で6頭まで | 94.0%［85.4〜103.2］ | 6.6% |
| E 3連複 ◎○-相手（確率上位6頭・6点） | 88.4%［84.0〜93.1］ | 15.9% |
| F 3連複 ◎○-相手（確率上位10頭・10点） | 90.3%［84.9〜95.9］ | 17.7% |
| G 穴🔥軸の3連複・相手=印の馬から2頭組（10点） | 77.3%［71.4〜83.9］ | 6.8% |
| H 穴🔥軸の3連複・相手=確率上位6頭から2頭組（15点） | 61.7%［55.7〜67.7］ | 4.7% |
| I 🔥と◎○の3頭だけの3連複（1点） | 96.5%［77.7〜118.1］ | 1.1% |

- 紐を広げると「何か当たる」は上がる（4.7→6.6%）が、回収率は上がらない（Aの97%は区間が広く偶然の範囲。従来の90〜93%と整合）。
- 穴を軸にして紐を広げた3連複は明確に悪い（G・Hは区間の上限が90%未満）。穴の紐を広げれば回収率が上がる、は支持されない。
- 結論: 広げる目的は「当たる頻度」。回収率の改善策ではない。K12の相手を「印4頭＋確率上位で6頭まで（D）」にするのは頻度目的なら有力。採用する場合も、型の閾値は同じ期間を見て決めているため前向き集計が必要。
- 道具: src/keiba-predictor/himo_test.py（版の入れ替わりは version_drop_test.py）（pattern_backtest.py と同じデータ・combo_backtest.predictions）。再実行が要るなら pattern_backtest.py に型として足す。

## 4. 運用の教訓
- 発売前の想定オッズの版は、人気薄の印（🔥・△）を出さない・出しても「実売で変わる」と明記する。前日発売が始まってから作り直す（ファンタジーSの教訓と同じ）。
- 印が前日と当日で入れ替わった馬は、買い目の紐から機械的に外さない候補にする（版を残して累計）。

## 5. 「前日の版で印があって当日消えた馬を、紐に1頭足していたら」の反事実（35レース・実払戻）
道具: src/keiba-predictor/version_himo_add.py（`fixed`＝1万円に固定して均等割り／`add`＝1点の金額は据え置いて点を足す。ユーザー指示「1万円きっかりの制限はない・1万円前後で」）。
| 券種 | 紐=最後の版の印だけ | ＋消えた馬を足す（add・1点の金額据え置き） | 的中レース |
|---|---|---|---|
| ワイド◎流し | 回収110%（+34,750円） | 98%（-9,150円・平均賭け13,100円） | 19→20 / 35 |
| 3連単マルチ◎○→紐 | 11% | 8% | 1 / 35 |
| 3連複◎○-紐 | 189%（+311,330円） | 136%（+173,430円） | 6 / 6 |
- 足した点で増えた払戻は64,600円、増えた賭け金は108,500円＝足した点の回収は約60%。当たるレースは1つ増えただけ（京都12R・東京4R・東京11Rの3レースで払戻が増えた）。1万円固定（fixed）でも ワイド110→101%。
- 35レースでは「足すと回収率が上がる」は確認できない（足した点の回収は標準的な水準を下回る）。標本が小さいので毎週積む。
