# 議事録：競馬YouTubeの動画構成と投稿の進め方

音声の書き起こしが元なので、聞き取りが怪しい箇所は「要確認」としています。

**日付**：2026-11-20（書き起こしの受領日。実施日は要確認）
**議題**：長尺動画の構成／ショート／投稿本数／収益化／対話動画の音声

## 1. 決まったこと

### 長尺動画の構成
- 長尺の中にシミュレーション（展開）を入れる。入れる場所は、対話形式の予想パート。
- 毎回同じ流れにして、コーナーをくっきり分ける。
  1. データ予想
  2. シミュレーション・展開予想
  3. 印の予想
  4. 買い目（穴予想を含む）
- 流れを固定するねらいは、穴だけ見たい人が最後だけ見れば分かるようにすること。
- コーナーごとにタイムスタンプを作り、YouTubeの概要欄に載せてチャプター表示にする。

### ショート
- 1本か2本。「きちんとまとめたもの」と「長尺から切り抜いたもの」の組み合わせ。

### 投稿本数
- 最初は「週末と直前の2本」の案だったが、足りないという話になり、週3本を目安にする。
  - 日曜か月曜：振り返り（当たっても外れても正直に出す）
  - 水曜ごろ：週の半ばの動画
  - 週末：最終予想
- 振り返りは、的中したときにサムネイルを強く作れる利点がある。
- 上げる日は休みの日に合わせてよい（日曜・水曜が多い）。
- 質は落とさず、本数で再生時間を稼ぐ。

### 対話動画の音声
- Google AI Studio（Gemini）の音声を使う。
- 回数の上限は、細切れで何度も作らず、話し手1人分を長尺でまとめて出す（2人なら2回）ことで避ける。
- 設定は前日に受け取った対話のスキルに入っている。分からなければ聞く。
- カード未登録のアカウントで使い、費用が高くついたら請求する（要確認）。

## 2. 共有された状況
- この10日ほどでチャンネル登録が約40人増えた。
- 収益化の課題は再生時間。条件は登録者1,000人以上と再生時間で、時間数は聞き取り不明（要確認）。
- このペースを半年ほど続ければ届く見込み、という見立て。
- 競馬のほか、漫画チャンネルでのアニメ投稿と、もう1つ（競輪と聞こえるが要確認）を合わせ、3チャンネルで動かす構想がある。
- 動画の気になる所（ズームで絵が切れている等）は、仕組みを少しずつ直していく。

## 4. 音声設定の確認結果
受け取ったスキル（`keiba-video-aiai-ss` と `src/keiba-predictor/video_kit`）を見たところ、話のとおりの設定が入っていた。
- **モデル**：`gemini-3.8-flash-tts`（Gemini TTS のみ）
- **声**：解説役アスメシは Leda、聞き役の競馬ファンは Puck（`video_kit/templates/voices.json`）
- **まとめ読み**：本編は `tts_chunks.js` で話し手ごとにまとめて読ませ、`split_chunks.py` で場面ごとに切る。
- **上限に当たったとき**：`.env` の `GEMINI_API_KEY`〜`GEMINI_API_KEY5` を順に切り替える。

`.env` にキーが実際に入っているか、カード登録の有無までは未確認。
