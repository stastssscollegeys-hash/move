# ユーザーの予想の考え方（口述の記録・随時追記）

2026-11-01 から、ユーザーが口頭で話した「予想で大事にしていること」を順に記録し、エンジン（`ev_engine.py` の特徴量）への落とし込み状況を対応づける。
音声入力のため言い回しは整理してある。**採用の可否は従来どおり前向きの検証（同じ人気帯で差が出るか・モデル確率に無い情報か）で決める**。

## 前提（買う・買わないの判断）
- 期待値が大事。まず「買えるレースか・買える馬券か」を考える。
- 回収率の概念も大事（目的は年間回収率100%超）。→ 現状反映済み（勝負レース制・E2・B1台帳）。

## 1. 馬の実力（予想のまず一点目）
見ること（口述）と、現状のエンジンでの扱い:

| 見ること | 現状 | 状況 |
|---|---|---|
| どういうタイム・ラップを刻んできたか | 時計の指数（馬場差補正・直近3走最良／前走／5走平均／同距離帯最良）= 特徴量53〜58 | 反映済み。**ラップの形（前半と後半の配分・減速の仕方）は馬ごとの特徴量になっていない**（前走のレースペースのみ=45） |
| どういうペース・位置取りをする馬か | 前で運ぶ割合（直近5走）=30、前走4角の位置=5、前走ペース×前走で前にいた=46 | 反映済み（ただしレース前にペースは当てられない=keiba_pace_unpredictable） |
| どういう馬と戦ってきたか（相手関係） | 前走クラス=50、クラス上げ下げ=14・15 | **不足**。同じレースに出ていた他馬のその後の成績（レースのレベル）は特徴量に無い |
| 他の出走馬との横比較（メンバー内の相対評価） | モデルがレース内で確率を正規化。人気との比＝割安さで印 | 反映済み（レース内相対） |
| ペース・コースに合うか（適性） | 傾向 コース×脚質/枠、同じ芝ダ×距離帯の経験=67・68、道悪経験=69・70 | 部分的。ペース適性（速い流れで好走する馬か）は馬ごとには無い |
| トラックバイアスに合うか | 当日・前週の偏りは説明文・判断材料。確率に入れる検証は不採用（SKILL §4） | 説明用のみ |

### この点から出る検証候補（未実施・事前登録してから前向きで測る）
1. **相手関係**: 前走のレースで、同じレースに出ていた他馬の「その後3走の成績」（レースレベル指標）を馬の特徴量にする。
2. **馬ごとのラップ型**: 直近走の「前半3F÷後半3F」のバランス、減速率を馬の特徴量にする（ペース適性の代理）。
3. **馬ごとのバイアス適性**: 過去に内有利・外有利の日に、その馬が好走した度合い。

## 2. レース・コースの特徴を捉える（過去10年ほどを遡った傾向）
見ること（口述）と、現状のエンジン・道具での扱い:

| 見ること | 現状 | 状況 |
|---|---|---|
| どういう馬が勝ちやすいレース・コースか（過去約10年の傾向） | `course_profile.py`（84コース・重賞132の型カード）、`race_profile.py`（重賞の過去10回）、`race_history.py`（人気別・枠・脚質・年齢・前走の集計） | 反映済み。重賞は1週間前プレビュー・前日最終版の説明文に出す。特徴量では「傾向 コース×脚質/枠/斤量帯/年齢/性別」=35〜42、「このレース 脚質/枠/年齢/前走クラス/人気帯/斤量帯」=47〜52 |
| 馬場（トラックバイアス）の傾向 | 前週・当日の偏りを説明文と判断材料に使用。確率に入れる検証は不採用（SKILL §4） | 説明用のみ |
| どういうペースになりやすいか | 距離帯別のペース×脚質の実測（`pace_style_audit.py`）。**レース前にペースは当てられない**（44.3%＜常にM45.6%）ので確率には使わない | 説明用のみ（コース・距離帯ごとの出やすさは表示可能） |
| どういう位置取りをした馬が勝ちやすいか | コース×脚質の傾向=35、馬場×脚質=37、「2番手以内=逃げ」で付け直した脚質表 | 反映済み。短距離ほど前有利、どのコースも3着内率は前＞後 |
| 血統（どういう血統の馬がいいか） | 種牡馬が市場評価より勝つ度合い=31〜34、傾向 コース×種牡馬=44・馬場×種牡馬=43。`sire_analysis.py`、条件付き候補は`db/sire_candidates.json`に事前登録（20260927〜・再評価待ち） | 部分的。種牡馬単体は両関門通過ゼロ。コース×種牡馬の組は前向き再評価が未了 |

### この点から出る検証候補（未実施）
1. **コース・レース単位の「勝ちやすい型」の自動出力を平場にも広げる**: 重賞だけでなく平場（同じ開催・同じ距離・同じクラス）の型カードを`predict_day`の説明文に出す。
2. **血統の事前登録分（sire_candidates.json）を2026-11-01時点で再評価**する（eval_from=20260927以降のレースが約5週分たまった）。
3. **コース別のペース傾向を表示**（採否ではなく説明用）: 距離帯・コース別の前半3F平均と、勝ち馬の脚質分布。
