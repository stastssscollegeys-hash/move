# コースの型 — 10年分（2016〜2026/10/12）から分かったこと（2026-10-14）

道具: `src/keiba-predictor/course_profile.py`（84コース・重賞132の型カード）
- 1枚引く: `python course_profile.py --course 京都芝2000m` ／ `python course_profile.py --race 秋華賞`
- 全カード: `docs/keiba_course_profile.md`（索引つき）・`競馬予想レポート/コース傾向/{コース名}.md`・`重賞_{レース名}.md`
- データ: `daily_pdca/db/course_profile.json`（予想・SNS文の素材）
- 人気を差し引いた「人気より走る・走らない条件」は `course_trends.py`（前半・後半とも同じ向きに出たものだけ）。型カードの最後の行に載る

カードの中身: 勝ち馬の人気（1番人気の勝率・3着内率、6番人気以下の勝ち）／配当（馬連・3連単の中央値、10万円超の割合）／枠ごとの3着内率／
勝ち馬の脚質と脚質ごとの3着内率／上がり最速の馬の成績／ペース（前3F・後3F、ハイ・平均・スローの割合、良馬場の勝ちタイム、平均ラップ）と
ペース別の前・後の有利不利／種牡馬（10年）・騎手（直近3年）の勝率・3着内率・単勝回収率／**今年の値を10年と並べた行**／重賞は回ごとの勝ち馬一覧

## 大事な修正: 脚質の定義

元データ（TARGET）の「脚質」は**最初のコーナー2番手以内を全部「逃げ」**にしていた（1レースに逃げが2〜3頭）。
コーナー通過順から付け直した: 逃げ＝最初のコーナーで先頭／先行＝最初のコーナーか4角で頭数の1/3以内／差し＝4角で2/3以内／追込＝それより後ろ。
これで東京芝1600mの「勝ち馬の逃げ」は28%→12%、中山芝1200mの逃げの3着内率45%（外部3ソースの45〜52%と一致）。
`course_trends.py`・`week_preview_data.py` も同じ定義に直した。**今週の秋華賞の投稿案の脚質の行も直した**（差し25%＞逃げ20%・先行19%＞追込9%。「最後方からは届きにくい」）。

## 10年で分かった型（150レース以上のコース）

**1. どのコースも「前に行った馬」が3着に残りやすい。** 差し・追込の3着内率が逃げ・先行を上回るコースは1つも無い
（一番差が小さい東京芝2400mでも 後ろ−前 = −7.5pt）。「直線が長いから差し」は3着内率では成り立たない。差しが勝つことはあるが、残るのは前。

**2. 枠の有利不利（内1〜3枠 − 外6〜8枠 の3着内率）**

| 内が有利 | 差 | 外が有利 | 差 |
|---|---:|---|---:|
| 中京芝1200m | +10.1pt | 新潟芝1000m（直線） | −18.2pt |
| 阪神芝1200m | +7.4pt | 新潟ダ1200m | −5.7pt |
| 函館芝1800m | +6.6pt | 東京ダ1600m | −5.4pt |
| 阪神芝1400m | +6.0pt | 新潟芝1200m | −4.5pt |
| 阪神芝2400m | +5.7pt | 中山ダ1800m | −4.4pt |
| 阪神芝1800m | +4.6pt | 阪神ダ1400m | −4.2pt |

傾向: **芝の短距離・阪神の芝は内**、**ダートのスタートが芝のコース（東京ダ1600・阪神ダ1400）と新潟は外**。

**3. 逃げが残るコース（逃げ馬の3着内率）**: 小倉ダ1000m 71%／函館ダ1000m 70%／福島ダ1150m 60%／阪神芝1200m 58%／札幌ダ1000m 58%／中京ダ1200m 53%

**4. 1番人気の勝率**: 強い＝東京芝2400m 41%・札幌芝1500m 40%・東京芝1800m 39%（直線が長い中距離）／弱い＝新潟芝1400m 26%・京都芝1400m 26%・中京芝1200m 26%・福島芝1200m 27%（短距離・小回り）

## 予想での使い方と注意

- 型カードの脚質・ペース・上がりは**結果から付けた値**。レース前には確定しない → 「この型ならこういう馬が来る」の読み・説明・SNSの根拠に使う
- **確率モデル（ev_engine）にはすでに枠・脚質の傾向が入っていて、市場もこれを織り込んでいる**（前日の内枠バイアスを足しても確率は改善しなかった）。型カードだけで買い目を変えない
- 種牡馬・騎手の単勝回収率は件数が少ないと偶然が大きい（n を必ず見る）
- 内回り・外回りは元データで区別できない（京都芝1400m・1600m、新潟芝2000m など、両方ある距離は混ざっている）
