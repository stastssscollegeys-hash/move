# 当日の極端なバイアスと休み明けの人気馬（2026-11-08 検証・`src/keiba-predictor/intraday_extreme_test.py`）

## きっかけ
2026-11-08（日）のみやこSでは、次の2つが起きた。
- ◎⑮ショウナンバンライ（8枠）が8着だった。この日の京都ダートは、7・8枠が24頭で3着内1回だった。
- 休み明け（約半年ぶり）を理由に×にした⑧テスティモーネ（5番人気）が2着に来た。

この2つから仮説を2つ立てて、蓄積DB（2016〜2026・35,996R・500,671頭）で確かめた。期待値（E）は「単勝オッズの帯×頭数の帯」ごとの全体の3着内率で、A/E が1なら市場はその傾向を織り込み済みという意味になる。

→ ただし、ユーザー方針（人気馬を切らない）は守る。休み明けの人気馬は△で3着内要員にとどめ、軸にはしない。

## 運用（確率は動かさない・前向きで確かめる）
- **D1**：当日の外枠の3着内が20頭以上で10%以下になったら、その後のレースでは外枠の馬を◎の単独軸にしない。◎が外枠のときは相手を厚くするか、2頭軸にする。
- **L1**：前走から150日以上の馬は、人気でも軸にしない。5番人気以内なら△で買い目に残す。
- 判定：11/9以降のレースで、web_review の照合のときに該当馬の3着内 A/E を積む。2回連続で再現したら、3着内×0.9を `web_frontier` に入れて試す。
