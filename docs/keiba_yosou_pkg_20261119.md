## 考え方メモの4点と、こちらの扱い

| メモ | 内容 | こちらの扱い |

| 1. オッズは「選ぶ」に使わず「買い方」だけに使う | 選ぶ段にオッズを入れると人気どおりになり、回収率は約100%が上限 | **採用しない**。こちらは市場の確率を土台にずれを足す作り（`ev_engine.py`・`benter.py`）で、20年分の前向き検証で単勝ルールB1 119.5%。外部の「オッズなし」モデルは◎単勝80.2%（1番人気76.2%）で、こちらの土台より下。ただし「必ず人気だけで選んだ場合と並べて見る」は今も守っている |
| 2. 騎手・調教師・血統の勝率は「その日より前」だけで数える | 全期間で数えると検証が良く見えすぎる | **本番は対応済み**。`ev_engine.py` は日付順に進め、その日の結果は日が終わってから足す（「その日が終わってから履歴を更新する」の箇所）。全期間の表を使うのは旧道具（`collect_weekend_bigdata.py`・`scripts/predict_*`）だけで、今は使っていない＝使うなら直してから |
| 3. 発信用の穴は別の物差しで見る | 穴の3着内率を同じ人気帯の平均と並べる。複勝回収68%＝見せ場用。外れも全部記録 | **採用**。SKILL §3m（B穴党版）に物差しと言い方の決まりを追加。穴の線引きはこちらの「6番人気以下」のまま（外部は8番人気以下） |
| 3'. 人気が見落とす情報＝「過去3走の勝ち馬との差（着順は悪くても僅差）」 | | **検証中**。`ev_engine.py` に候補の項目3つ（`WINMARGIN=1` のときだけ学習に使う）を足し、年ごとの前向き検証で比べる |
| 4. 検証の決まり | 学習と成績の期間を分ける・回数を見る・選んだ条件は後のレースだけで数える | 既にこちらの決まり（前向き台帳・事前登録）と同じ |

## 勝ち馬との差（WINMARGIN）の検証

- 項目: 「勝ち馬との差（直近3走の最小・秒）」「直近3走で4着以下かつ0.5秒差以内の回数」「勝ち馬との差データなし」
- 差は、そのレースの1着馬の走破タイムとの差（同じ日の結果は翌日以降の特徴量にだけ使う）
- 比べ方: `LEAN=1 EV_FROM_YEAR=2016 python ev_engine.py --walk` と、同じく `WINMARGIN=1` を付けたもの
- 採用の基準: これまでと同じ（年ごとの前向き検証で対数尤度差が上がり、多くの年で改善）
- 結果（2026-11-19・2016年以降のデータ・2019〜2026年を1年ずつ検証・25,873レース）: **不採用**

| 年 | 今のまま 対数尤度差 | 勝ち馬との差あり | 割安(EV≧1.0)の単勝 今のまま | 差あり |
|---|---|---|---|---|
| 2019 | +0.00466 | +0.00431 | 110.3% | 95.1% |
| 2020 | +0.00581 | +0.00627 | 107.1% | 96.6% |
| 2021 | +0.00756 | +0.00790 | 100.9% | 93.6% |
| 2022 | +0.00986 | +0.01085 | 117.4% | 96.9% |
| 2023 | +0.00550 | +0.00548 | 70.2% | 67.4% |
| 2024 | +0.00454 | +0.00472 | 118.9% | 98.3% |
| 2025 | +0.00705 | +0.00640 | 95.1% | 80.0% |
| 2026 | +0.00877 | +0.00882 | 128.9% | 107.3% |
| 全年 | +0.00668［+0.00520, +0.00824］ | +0.00681［+0.00530, +0.00840］ | | |

- 確率の当たり具合はわずかに上がった（8年中5年）が、区間はほぼ重なる。割安な馬を買う成績は8年中7年で下がった（買う点数が増え、割安と出る馬の質が落ちた）
- 採用の目安（調教は8年中7年で改善して採用・馬体重の組み合わせは4年で不採用）に届かない。項目は `WINMARGIN=1` で試せる形のまま残す
- 読み: 「僅差負け」は、こちらの土台（市場の確率）にはすでにほぼ入っている。外部のメモの「人気が見落とす」は、オッズを使わないモデルの中での話
- 🟡 `--walk` の最後の回収率の区間（`roi_ci`）は、空きメモリが1GB未満だと790MBを確保できずに止まる。対数尤度差と年ごとの表はその前に出るので比較には足りる

## 外部の穴モデル（lgb_ana_top3）を使うとき

- オッズなしで3着以内の点数を出す。決め方は「点数がレースで5位以内、かつ朝の時点で8番人気以下の中で1位」
- 使い方は置き場所の README（当日の朝 `paper_trade_predict.py --date YYYYMMDD` → `summary.py`）。smartrc・netkeiba から取るので、何日分もまとめて取らない
- こちらでは**参考の2つ目の目**。B穴党版の穴◎は本線の確率の割安さで決め、外部モデルの穴と重なったら1行添える程度
