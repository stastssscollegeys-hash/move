## 3. 反省（何を間違えたか）
- **同じ買い目の使い回し**（JBC2レースで同じ3連複＋ワイド）→ ユーザー指摘。型選択（kaime_compose）があるのに、地方だからと手で固定形を書いた。
- **◎の決め方**: 「55kg・3歳・前走2着」という強みで◎にしたが、市場比（見立て÷市場）ではほぼ等価で、割安ではなかった。実際は初の古馬戦・初の金沢2100m・追込脚質という不確実性が大きかった。印は割安さ順（`keiba_value_marks`）の原則に戻す。
- **他種のレースのデータを流用**: 馬体重4kg以上減は不利という傾向は**スプリントの過去15回**の表。クラシックには当てはまらず、−10kgのホウオウルーレット、−11kgのセラフィックコールは2・3着だった。
- **1レースの傾向で確率を動かした**: 「レディスで前有利」だけで後方まくり型を下げた。n=1は材料にしない（事前登録した補正だけを使う）。
- **直前の見直しで買い目をぶらした**（v1→v4）。事前に決めた手順（型→見立て確率→期待値→ガミ判定）を1回回し、最終版は馬体重・実オッズが出た後に1回だけ作る（天皇賞の教訓と同じ）。
- **スプリント**: ハチローを「−7kg・距離短縮（1600→1400m）」で△に下げたが勝った（前走・南部杯の勝ち馬）。前走勝ち＋人気が2番手の馬を印から下げるには根拠が弱かった。
- **直前の確認漏れ**: 固定リストの予想家（動画）はJBCの予想が見つからず、集計に入れられなかった。パドック・返し馬も未確認。
- X下書き1本（結論）が、画像だけ残って本文が空になっていた（保存のしかたの不具合）。保存後に必ず本文の有無を確かめる。

## 4. 直した仕組み・ルール
- `kaime_compose.py`: `enforce_no_gami`（Σ(1/オッズ)≦0.90＝どの1点が当たっても投資を上回る）を本番経路（p_fn あり）に追加。**注意: 軸が外れたときの保険（低オッズ）を落とす副作用がある**。→ 今後は、軸を◎に集中させる前に、軸が外れた場合の最悪（全滅）を許容できるか、2頭軸（◎と▲の両方を軸にする）が要るかをレースごとに判断する。保険を入れる場合は「ガミる保険」を明示して少額に（ガミ防止の例外にはしない）。
- SKILL.md「馬券・金額」に追記済み（ガミる買い方は基本しない／買い目はレースごとに型と予算を計算で決める）。メモリ `feedback_keiba_kaime_per_race_not_fixed`。

## 5. 地方・交流重賞（JBC等）の手順（次回のJBC・Jpn1用）
1. 出走表・近5走（netkeiba NAR `shutuba_past`）、オッズ（単勝・馬連・ワイドの `type=b4/b5`。3連複は取れないことが多い）、調教（keiba.go.jp 特設・ウマニティ）、過去傾向（ファクター表・過去10年）を集める。
2. 見立て確率を**1回だけ**出す（補正はルール化した範囲だけ。他種のレース・1レースの傾向は使わない）。市場確率との比で印を割安さ順に付ける。
3. `kaime_compose.compose` で型を選ぶ（make_ctx に p・q・pop）。期待値と全体の期待回収率を出し、ガミ判定を通す。軸が外れたときの全滅が許せない場合は2頭軸にする。
4. 馬体重・実オッズが出たら**1回だけ**作り直す。直前に何度も作り直さない。
5. 結果が出たら本書のように、版ごとの事後試算と反省を残す。
