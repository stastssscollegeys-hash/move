## まとめ（2026-10-14）

**体重そのもの**: 軽い馬は人気ほど走らない。〜419kg 比0.86・単勝回収率49%、420〜439kg 0.96・59%（全馬72.7%）。
ダートの短距離で一番強く（〜419kg 0.78）、芝の長距離ではほぼ消える。同じレースで一番軽い馬も 0.91〜0.92。
**増減は間隔で意味が変わる**: 休み明け（13週〜）で12kg以上減は 0.81（増えた馬 0.95 より悪い）／中5週以内で12kg以上増は 0.89・単回53%／
牝馬は大きく減っても（0.89）増えても（0.94）走らない／3着内に来たときの体重から±6kg以内は 1.04。

**予測への反映**:
- 採用（HORSEFIT・既定で有効）: 馬体重（470kgとの差）・439kg以下 ほか馬の得意条件6つ → 前向き +0.00601→+0.00633・8年中7年改善
- 不採用（WEIGHT2=1 で試せる）: 休み明け×減り・中5週×大幅増・牝馬×増減の大きさ・レースで一番軽い・好走時の体重との離れ・ダート×体重
  → +0.00633→+0.00633・改善4/8年。組み合わせは既存の「増減」「体重」「休み明け」「牝馬」と市場で説明できている
- 本番で馬体重が入っていなかった不具合（本体 --quick）の直し方: `docs/keiba_patch_quick_weight.md`（部品 `weight_refresh.py`）
