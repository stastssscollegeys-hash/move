# どんなレースで、どんな馬が走るか（20160105〜20261012・499,771走・57,634頭）

指標: **比** = 3着内の実数 ÷ 人気（×頭数帯）から期待される3着内の数（1.00＝人気どおり、1.10＝人気より1割多く3着内）。**単回** = その条件の馬の単勝を全部100円ずつ買ったときの回収率（市場平均は約80%）。
**安定** = 前半（〜2022）と後半（2023〜）の両方で同じ向き、かつ |z|≧3。安定でないものは偶然の可能性が高い。800走以上のみ。
特徴はすべて**レース前に分かる値**（前走までの成績・今回の条件）。ただし ev_engine の確率にはこの多くがすでに入っていて、市場もかなり織り込んでいる。**単回が80%前後なら市場が正しく織り込み済み、明らかに高い・低いものだけが「市場の穴」の候補。**
