# YouTube動画リサーチツール セットアップガイド

このツールを使うには **2つのAPIキー** が必要です。
以下の手順に従って取得してください。

---

## 1. YouTube Data API キーの取得（無料）

### 手順

1. **Google Cloud Console にアクセス**
   - https://console.cloud.google.com/
   - Googleアカウントでログイン（なければ作成）

2. **プロジェクトを作成**
   - 画面上部のプロジェクト選択メニュー → 「新しいプロジェクト」
   - プロジェクト名は何でもOK（例: `youtube-research`）
   - 「作成」をクリック

3. **YouTube Data API v3 を有効化**
   - 左メニュー「APIとサービス」→「ライブラリ」
   - 検索バーに `YouTube Data API v3` と入力
   - 表示された項目をクリック →「有効にする」

4. **APIキーを作成**
   - 左メニュー「APIとサービス」→「認証情報」
   - 「+ 認証情報を作成」→「APIキー」
   - 表示されたキーをコピー（`AIza...` で始まる文字列）

5. **（推奨）キーを制限する**
   - 作成したキーの右側「︙」→「キーを編集」
   - 「APIの制限」→「キーを制限」→ `YouTube Data API v3` のみ選択
   - 「保存」
   - ※ 万が一キーが漏洩しても、YouTube以外のサービスへの不正利用を防げます

### 料金

| 項目 | 内容 |
|------|------|
| 無料枠 | **1日10,000ユニット** |
| 1回の分析で使うユニット | 約120〜200 |
| 1日の分析回数（無料内） | **約50〜80回** |
| クレジットカード登録 | **不要** |

通常の個人利用であれば完全無料で使えます。

---

## 2. Anthropic API キーの取得（従量課金）

### 手順

1. **Anthropic Console にアクセス**
   - https://console.anthropic.com/
   - アカウントを作成（メールアドレスで登録）

2. **APIキーを作成**
   - ログイン後、左メニュー「Settings」→「API Keys」
   - 直接リンク: https://console.anthropic.com/settings/keys
   - 「Create Key」をクリック
   - 名前を入力（例: `youtube-research`）→ 作成
   - 表示されたキーをコピー（`sk-ant-...` で始まる文字列）
   - **キーは作成時の1回しか表示されません。必ずコピーして保存してください**

3. **クレジットを追加**
   - 左メニュー「Settings」→「Billing」
   - クレジットカードを登録し、APIクレジットを追加
   - **最初は $5（約750円）でOK**

### 料金

| 項目 | 内容 |
|------|------|
| 1回の分析コスト | **約1〜5円**（$0.01〜0.05） |
| $5で分析できる回数 | **100回以上** |
| 月額固定費 | なし（使った分だけ） |

※ トレンド判定やターゲット分析など、AIを使う機能で消費されます。
※ YouTube検索だけ（Step 1）ではAnthropicの料金はかかりません。

---

## 3. ツールにキーを設定する

1. ツール画面上部の「**APIキー設定**」をクリックして開く
2. YouTube Data API キーを入力
3. Anthropic API キーを入力
4. 「**キーを保存**」をクリック

キーはお使いのブラウザに保存されます（サーバーには保存されません）。

---

## 4. 使い方

### Step 1: YouTube検索（無料・高速）
- キーワードやジャンルを入力して「検索」
- 動画一覧がバズ比率（再生数÷登録者数）順で表示されます

### Step 2: 気になる動画を選択
- チェックボックスで分析したい動画を選択
- 「バズ動画のみ選択」ボタンで高バズ動画だけ選ぶこともできます

### Step 3: 分析を実行
- **トレンド判定**: 選択した動画のテーマが今発信して間に合うかを判定
- **ターゲット＆キーワード分析**: 選択した動画からターゲット層とキーワードを抽出

## よくある質問

**Q: APIキーは安全ですか？**
A: キーはブラウザのローカルストレージに保存され、分析リクエスト時のみサーバーに送信されます。サーバー側には保存されません。

**Q: YouTube APIの無料枠を超えたらどうなりますか？**
A: 翌日にリセットされます。追加料金は発生しません。上限に達すると検索ができなくなるだけです。

**Q: Anthropicのクレジットがなくなったら？**
A: トレンド判定やターゲット分析がエラーになります。Billing画面からクレジットを追加してください。YouTube検索（Step 1）は引き続き使えます。
