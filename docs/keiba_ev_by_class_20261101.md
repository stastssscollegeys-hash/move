## 読み取り
- 回収が100%を超えるのは2勝以上（3勝・OP）だが、**上位10件の高配当を除くと41〜81%に落ちる**＝少数の大当たり依存で、区間も100%をまたぐ。確定した優位ではなく「傾向」止まり。
- **重賞は比≧1.2でも54%**（上位10除き24%）。重賞は割安の単勝を選ぶ根拠にならない（G1で◎が人気に及ばなかった実績とも整合）。
- 未勝利・1勝は割安選びでも100%に届かない。
- 標本が小さいクラスほど年別がぶれる（OPは48〜565%）。クラス7×閾値2×年8の見方で偶然が混ざる。

## 使い方
- 採用しない。B1台帳（単勝ルール）の結果を**クラス別に積み上げ**、3勝・OPの傾向が前向きに再現するか見る。
- 重賞の割安単勝は買い候補にしない（印・説明用の参考表示のみ）。
