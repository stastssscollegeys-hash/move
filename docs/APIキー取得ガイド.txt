========================================
  YouTube動画リサーチツール
  APIキー取得ガイド
========================================

このツールを使うには「YouTubeのAPIキー」と
「AnthropicのAPIキー」の2つが必要です。

以下の手順で取得してください。


────────────────────────────────────
■ 1つ目: YouTube Data API キー（無料）
────────────────────────────────────

【料金】 完全無料（クレジットカード登録も不要）
【目安】 1日50〜80回の分析が無料でできます


▼ 取得手順

(1) 以下のURLをブラウザで開く
    https://console.cloud.google.com/

(2) Googleアカウントでログインする
    ※ 普段使っているGmailのアカウントでOKです

(3) 画面上部の「プロジェクトの選択」をクリック
    → 「新しいプロジェクト」をクリック
    → プロジェクト名を入力（何でもOK。例: youtube-tool）
    → 「作成」をクリック

(4) 左側メニューの「APIとサービス」をクリック
    → 「ライブラリ」をクリック

(5) 検索バーに「YouTube Data API v3」と入力して検索
    → 表示された「YouTube Data API v3」をクリック
    → 「有効にする」ボタンをクリック

(6) 左側メニューの「APIとサービス」をクリック
    → 「認証情報」をクリック
    → 上部の「＋認証情報を作成」をクリック
    → 「APIキー」をクリック

(7) 画面にAPIキーが表示されます
    「AIza」で始まる文字列です
    → これをコピーして保存してください


────────────────────────────────────
■ 2つ目: Anthropic API キー（従量課金）
────────────────────────────────────

【料金】 1回の分析で約1〜5円
         最初に500〜1000円分チャージすればOK
         （100回以上分析できます）
【注意】 クレジットカードの登録が必要です


▼ 取得手順

(1) 以下のURLをブラウザで開く
    https://console.anthropic.com/

(2) 「Sign Up」からアカウントを作成する
    ※ メールアドレスで登録できます

(3) ログイン後、左メニューの「Settings」をクリック
    → 「API Keys」をクリック
    または、以下のURLを直接開く
    https://console.anthropic.com/settings/keys

(4) 「Create Key」をクリック
    → 名前を入力（何でもOK。例: youtube-tool）
    → 作成をクリック

(5) 画面にAPIキーが表示されます
    「sk-ant-」で始まる文字列です
    → これをコピーして保存してください

    ★★★ 重要 ★★★
    このキーは作成した時の1回しか表示されません！
    必ずコピーしてメモ帳などに保存してください。

(6) クレジットをチャージする
    左メニュー「Settings」→「Billing」
    → クレジットカードを登録
    → 最初は $5（約750円）で十分です


────────────────────────────────────
■ ツールにキーを設定する方法
────────────────────────────────────

(1) ツールの画面を開く

(2) 画面上部の「APIキー設定」をクリックして開く

(3) 「YouTube Data API キー」の欄に
    先ほどコピーした「AIza...」のキーを貼り付け

(4) 「Anthropic API キー」の欄に
    先ほどコピーした「sk-ant-...」のキーを貼り付け

(5) 「キーを保存」ボタンをクリック

    → これで準備完了です！


========================================
  ツールの使い方
========================================


────────────────────────────────────
■ 全体の流れ
────────────────────────────────────

このツールは3ステップで使います。

  Step 1: YouTubeを検索 → 動画一覧＋バズ判定が出る
  Step 2: 気になる動画を選ぶ
  Step 3: 選んだ動画を詳しく分析する


────────────────────────────────────
■ Step 1: YouTube検索（無料・すぐ出る）
────────────────────────────────────

(1) 画面上部の検索バーにキーワードを入力する
    例: 「AI副業」「プログラミング 独学」「ChatGPT 使い方」

(2) ジャンルを選ぶこともできます（任意）
    教育 / テック / ビジネス / ライフスタイル / エンタメ
    ※ キーワードだけでもOK、ジャンルだけでもOK、両方でもOK

(3) 絞り込み条件を設定する（任意）
    ・動画の長さ: ショート / ミディアム / ロング
    ・投稿期間: 1週間以内 / 1ヶ月以内 / 3ヶ月以内 / 1年以内
    ・取得件数: 10〜50件

(4) 「検索」ボタンを押す

(5) 結果が表示されます
    動画が一覧で出てきます。
    右側に「バズ比率」と「判定」が表示されます。

    ┌────────────────────────────────┐
    │  バズ比率とは？                │
    │                                │
    │  再生数 ÷ チャンネル登録者数   │
    │  の倍率のことです。            │
    │                                │
    │  例: 登録者1,000人なのに       │
    │      再生数100,000回           │
    │      → バズ比率 = 100倍！      │
    │                                │
    │  この数値が高いほど            │
    │  「登録者が少ないのに          │
    │   やたら再生されている」       │
    │  = バズっている動画です。      │
    └────────────────────────────────┘

    判定の見方:
    ・超バズ（10倍以上）= かなりバズっている！
    ・バズ  （5〜10倍）= バズっている
    ・好調  （2〜5倍） = 普通より良い
    ・平均  （1〜2倍） = 普通
    ・低調  （1倍以下） = 登録者数ほど見られていない

    ※ この検索はYouTube APIだけで動くので
      Anthropicの料金はかかりません（無料）


────────────────────────────────────
■ Step 2: 動画を選ぶ
────────────────────────────────────

検索結果が出たら、詳しく分析したい動画を選びます。

(1) 各動画の左側にチェックボックスがあります
    分析したい動画にチェックを入れてください

(2) 便利なボタン:
    ・「全選択」→ 全部にチェックを入れる
    ・「選択解除」→ チェックを全部外す
    ・「バズ動画のみ選択」→ バズっている動画だけ自動で選ぶ

    ★おすすめ: まずは「バズ動画のみ選択」を押して、
    バズっている動画だけを分析するのが効率的です。


────────────────────────────────────
■ Step 3-A: トレンド判定（AIが判定）
────────────────────────────────────

「トレンド判定」ボタンを押すと、
選んだ動画のテーマについて
「今からこのテーマで発信しても間に合うか？」を判定します。

結果の見方:

  ・Google Trends（Googleでの検索トレンド）
    ↑ 上昇 = 今まさに注目されている
    → 横ばい = 安定して検索されている
    ↓ 下降 = 興味が薄れてきている

  ・YouTube検索（YouTubeでの検索トレンド）
    ↑ 上昇 = YouTube内で盛り上がっている
    → 横ばい = 一定の需要がある
    ↓ 下降 = YouTube内での関心が下がっている

  ・競合度（同じテーマで動画を出しているチャンネルの数）
    少 ○ = ライバルが少ない（チャンス！）
    普通 △ = それなりにいる
    多 × = ライバルが多い（差別化が必要）

  ・総合判定
    「今すぐ出すべき！」
      → トレンド上昇中＋競合少ない = 最高のタイミング

    「先行者優位を取れる」
      → まだ競合が少ないテーマ = 早く出せば有利

    「チャンスだが競争激しい」
      → 需要はあるがライバルも多い = 差別化が必要

    「ニッチで安定的」
      → 大きくはないが安定した需要がある

    「タイミング遅い」
      → トレンド下降中＋競合多い = 別のテーマを検討

    ┌────────────────────────────────┐
    │  つまり...                     │
    │                                │
    │  「今すぐ出すべき！」          │
    │  「先行者優位を取れる」        │
    │  が出たテーマは                │
    │  すぐにコンテンツを作るべき！  │
    │                                │
    │  「タイミング遅い」が出たら    │
    │  別のキーワードを試しましょう  │
    └────────────────────────────────┘

  ※ この機能はAI（Anthropic）を使うので
    1回あたり約1〜3円かかります


────────────────────────────────────
■ Step 3-B: ターゲット＆キーワード分析（AIが分析）
────────────────────────────────────

「ターゲット＆キーワード分析」ボタンを押すと、
選んだ動画を元に以下の4つを分析します。


▼ ターゲット層
  「この動画を見ている人はどんな人か？」を分析します。

  ・デモグラフィック: 年齢層、性別、職業
  ・興味・関心: どんなことに興味がある人か
  ・課題・悩み: どんな悩みを持っている人か
  ・視聴動機: なぜこの動画を見ているのか
  ・購買行動: どんな商品やサービスを買いそうか

    ┌────────────────────────────────┐
    │  これが分かると...             │
    │                                │
    │  「誰に向けて」本や記事を      │
    │  書けばいいかが分かります。    │
    │                                │
    │  例: AI副業の動画の視聴者は    │
    │  「30代男性・会社員・副業に    │
    │   興味がある・本やオンライン   │
    │   講座を買う傾向がある」       │
    │  → この人たちに向けて          │
    │    コンテンツを作ればOK        │
    └────────────────────────────────┘


▼ キーワード
  動画の内容から、使えるキーワードを抽出します。

  カテゴリの意味:
  ・メイン: その分野の中心的なキーワード
  ・サブ: メインに関連するキーワード
  ・ロングテール: 具体的で競合の少ないキーワード
    （例:「AI 副業 初心者 2026」）
  ・購買意図: 商品を買いたい人が検索するキーワード
    （例:「AI副業 おすすめ本」「ChatGPT講座 比較」）
  ・質問系: 疑問形のキーワード
    （例:「AI副業って稼げるの？」）
  ・トレンド: 今注目されているキーワード

  ボリューム: 検索されている量（高/中/低）
  競合度: ライバルの多さ（高/中/低）

    ┌────────────────────────────────┐
    │  おすすめの使い方               │
    │                                │
    │  ・本のタイトル候補            │
    │    → メインキーワードを入れる  │
    │                                │
    │  ・ブログやnote記事            │
    │    → ロングテールを狙う        │
    │    （競合が少なくて上位表示    │
    │     しやすい）                  │
    │                                │
    │  ・商品・サービス紹介          │
    │    → 購買意図キーワードを使う  │
    │                                │
    │  ・YouTube動画のタイトル        │
    │    → 質問系キーワードが        │
    │      クリックされやすい        │
    └────────────────────────────────┘


▼ 次のアクション
  分析結果を元に「次に何をすべきか」の
  具体的なアドバイスが表示されます。


▼ フルレポート
  上記すべてをまとめたレポートです。
  「レポートをコピー」ボタンで
  テキストとしてコピーできます。

  ※ この機能はAI（Anthropic）を使うので
    1回あたり約3〜5円かかります


────────────────────────────────────
■ 活用の具体例
────────────────────────────────────

【例1: 本を出したい場合】
  (1) 自分が書きたいテーマで検索
      例: 「ChatGPT 活用」
  (2) バズ動画を選択してトレンド判定
      → 「今すぐ出すべき！」なら本のテーマに決定
  (3) ターゲット＆キーワード分析
      → ターゲット層 = 本の想定読者
      → キーワード = タイトルや章立ての参考に

【例2: YouTube動画を作りたい場合】
  (1) 作りたいジャンルで検索
  (2) バズ動画をチェック
      → 「なぜこの動画がバズったのか」の参考に
  (3) トレンド判定で「今出しても遅くない」テーマを選ぶ
  (4) キーワード分析で動画タイトルや説明文に使う
      キーワードを決める

【例3: ブログ・note記事を書きたい場合】
  (1) 書きたいテーマで検索
  (2) バズ動画のターゲット層を確認
      → 記事の読者像が分かる
  (3) キーワードの「ロングテール」を確認
      → 記事タイトルやSEO対策に使う


────────────────────────────────────
■ よくある質問
────────────────────────────────────

Q: お金はかかりますか？
A: YouTube検索（Step 1）は完全無料です。
   トレンド判定は1回約1〜3円、
   ターゲット＆キーワード分析は1回約3〜5円です。
   $5（約750円）チャージすれば100回以上使えます。

Q: YouTubeの無料枠を使い切ったらどうなりますか？
A: 翌日に自動でリセットされます。
   追加料金は一切かかりません。

Q: APIキーは安全ですか？
A: キーはあなたのブラウザにだけ保存されます。
   サーバーに保存されることはありません。

Q: APIキーを忘れた・なくした場合は？
A: 同じ手順で新しいキーを作成できます。
   古いキーは削除してください。

Q: バズ比率が高い動画が見つからない場合は？
A: キーワードを変えてみてください。
   また、「投稿期間」を「1ヶ月以内」にすると
   最近バズった動画が見つかりやすいです。

Q: トレンド判定で「タイミング遅い」と出たら？
A: そのテーマはライバルが多すぎるかもしれません。
   キーワードを少し変えて（より具体的にして）
   もう一度試してみてください。
   例: 「AI」→「AI × 英語学習」「AI × 家計管理」

Q: 分析結果をどう使えばいいか分からない
A: まずは「次のアクション」に表示される
   アドバイスに従ってみてください。
   ターゲット層やキーワードは、本の企画書や
   ブログの構成を考えるときの参考資料として使えます。
