# 展開・馬場バイアスを何百万回もシミュレーションして買い方を決める案の検証（2026-11-01）

## 問い
今日の結果を受けて「展開（ペース）と当日の馬場バイアスを確率的に変えながら何万〜何百万回もレースを回し、最も期待値の取れる買い方を見つける」ことで、的中率・回収率を上げられるか。

## 検証1: 展開シナリオは予想を良くするか（`mc_scenario_test.py`）
- データ: ev_engine の年ごと前向き予測 p、25,440レース（2019〜）。学習=2022年まで（12,963R）、検証=2023年〜（11,964R）。
- 混合モデル: レースごとに潜在シナリオ（ペースZp・外枠有利Zb、どちらも標準正規）を引き、前で運ぶ馬／外の馬の強さを傾けて λ-Harville。シナリオ平均が混合確率。評価は実際の上位3頭の順序の対数尤度。
- 結果:
  - ペース（前で運ぶ馬を傾ける）: 強さを上げるほど悪化（学習で−6‰/R〜−50‰/R）。「レース前にペースは当てられない」（keiba_pace_unpredictable）と同じ結論。
  - 外枠有利の揺らぎ: 最適は強さ0.8〜1.0で検証 +1.5‰/R（z≈+1.6、有意でない）。1.5以上は検証で悪化（z=−3.2）、年別に安定しない。
- 結論: 潜在シナリオを足しても、素の確率を超える改善は確認できない。採用しない。

## 検証2: 100万回超のシミュレーションで買い目を決められるか（`mc_portfolio.py`）
- 200万回で天皇賞(秋)の全券種の確率と期待値を集計（13:50のオッズ）。サンプリングは入力の確率を再現するだけで、厳密計算と同じ答えになる（回数を増やすのは誤差を減らすだけ）。
- 期待値≧1.0の組が大量に出た（馬単75通り・3連複188通り・3連単2,216通り）。上位は⑤⑦・⑤⑰・②⑰など、230倍前後の馬を含む組で、的中確率は0.01〜0.5%。3連単の平均期待値が1.31＝市場より高く見えるのは、人気薄の確率の過大評価（既知: keiba_roi_research_20261030「人気薄の歪みは40倍超だけ」、穴軸3連複62〜77%）。
- 結論: 期待値の高い順に買うと穴の組に偏り、過去検証（全券種を期待値で選ぶと87%）と同じ負け方になる。実運用には使わない。

## わかったこと（今日の結果と合わせて）
1. 回収率を上げる源は「買い方の最適化」でも「展開の場合分け」でもなく、市場より正しい確率を出すこと。現状で前向きに確認できているのは単勝ルールB1（市場＋木・119.5%）だけ。
2. 買い方で変わるのは当たる頻度と外れ方（keiba_bet_structure_20261010）。今日の天皇賞は二強軸の形が全滅した例。
3. 当日のバイアスは「続く」傾向はあるが確率の改善にならない（SKILL §4）。説明文と判断材料に使う。
4. 次に試す価値があるもの（未実施）: ①B1（単勝）の発走30分前登録を日曜も自動で回して標本を貯める、②二強型での▲1着形を型別に前向き集計、③シミュレーションは「確率を市場へ縮める（過大評価の補正）」の検証に使う。
