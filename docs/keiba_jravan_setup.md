## 無料で進める方法（2026-10-02 夕方に開始・こちらが先行）
netkeiba の無料公開ページ（レース結果・確定オッズ・払戻）から過去分を集める。`src/keiba-predictor/history_backfill.py`。
- 対象: 2026→2025→…→2021年（約2万レース）。1ページごとに1.5秒以上あける。全部で20時間前後。
- 保存先: `Desktop/競馬予想レポート/daily_pdca/db/history/results_YYYY.json`・`payouts_YYYY.json`（蓄積DBとは別。旧エンジンに影響なし）
- 進み具合: `python history_backfill.py --status` ／ ログ `db/history/backfill_log.txt`
- PCの電源を切る・スリープすると止まる。**同じコマンドで続きから再開できる**:
  `python history_backfill.py --years 2026 2025 2024 2023 2022 2021`
- 貯まったら: `python ev_engine.py --fit --source "<…/db/history>"`（フォルダを渡すと全年を読む）
- 無料ページに無いもの: 種牡馬（父）・時系列オッズ・全組み合わせのオッズ。父は既存の血統キャッシュで補う。
  時系列オッズが必要になったら、下のJRA-VAN（無料体験1か月）を使う。

## JRA-VANを使う場合（契約・インストールは本人の操作が必要）
1. Microsoft Edge で https://jra-van.jp/dlb/dlrt_web.html を開き、**JV-Link** をインストールする。
   - 無料体験はJV-Linkのインストール日から1か月。継続は月額2,090円（税込）。体験だけなら有料登録は不要と案内されている。
   - 期間終了後に自動で課金されるかどうかは体験ページに明記が無い。申込み時に確認すること。
2. データベース構築ソフト **EveryDB3**（無料・https://everydb.iwinz.net/ ）をインストールする。
   - JRA-VANのデータをデータベースに取り込むソフト。旧版EveryDB2はSQLiteに対応していた。EveryDB3でもSQLiteを選べるかはインストール時に確認する（選べなければ SQL Server Express 等でもよい）。
3. EveryDB3 で「セットアップ（蓄積系データ）」を実行する。まずは **レース・馬毎レース情報・払戻・単複オッズ** を、取れる限り過去まで。
   - 初回は時間がかかる（数時間の見込み）。保存先はPC固有の場所でよい（例: `C:\keiba_db\jravan.db`）。git管理下には置かない（容量が大きい）。
4. 終わったら「取り込み終わった」と伝える。保存先のパスも。

## こちらで行うこと（取り込みが終わってから）
1. データベースの表と列を実物で確認し、`ev_engine.py` が読む形式（下記の列）に変換するスクリプトを書く。
   - 必要な列: date 競馬場 R 馬番 馬名 着順 単勝オッズ 人気 距離 タイム 後3F順位 馬体重 斤量_kg 性齢 騎手 厩舎 父 中日数 脚質
2. `python ev_engine.py --fit --source <変換後のJSON>` で学習と検証をやり直す（前半60%学習・後半40%検証・関門A/B）。
3. 数年分あれば使える特徴量を足す（馬ごとの時計の指数の履歴、クラスの上げ下げ、コース別の適性、時系列オッズの動き）。足すたびに同じ検証を通す。
4. 関門を通ったモデルだけを稼働させ、前向き台帳で回収率を追う。
