# 戦略トーナメント 第1回の結論と、これからの進め方（2026-10-14）

目的: 年単位で収支をプラスにする。そのために「複数の買い方を同じ物差しで並べ、どれが本当に回収率100%を超えるか」を決める。
道具: `src/keiba-predictor/strategy_tournament.py`（詳細の表は `docs/keiba_strategy_tournament.md`。実行のたびに作り直す）

## やったこと

- 2019〜2026年の25,670レースを、**その年より前のデータだけで学習したモデル**で予測（毎年学習し直す前向き検証）
- 7券種・33の買い方 ＋ 期待値型8つ × 15の条件（芝ダ・距離・クラス・馬場・頭数）＝ **153通り**を、確定オッズと実際の払戻で採点
- **2019〜2023年で候補を選び、2024〜2026年で同じ条件のまま確かめる**。多く試すほど偶然の当たりが混ざるので、選ぶ段階で補正（Benjamini-Hochberg）をかけた

## 結論

1. **ふつうの買い方は全部負ける。** 1番人気の単勝 79.3%、モデル1位の単勝 81.3%、ボックス・流し（馬連・ワイド・3連複・3連単）は 74〜83%。モデルは人気より少し賢いが、手数料（20〜27.5%）にはまったく届かない
2. **勝ち目があるのは「モデルと市場の見立てがずれた馬だけを単勝で買う」形。** ベンターと同じ結論
   - 単勝・モデル確率が市場の1.3倍以上・20倍以下: **109.6%［95〜124%］・8年中7年プラス・発見110%→確認107%**（一番安定）
   - 単勝・EV≧1.0・10倍以下: 108.4%［99〜118%］・6/8年。ただし確認期間は98%
3. **「3〜6倍の単勝（T1）」は後付けの当たりだった疑いが強い。** 発見期間126%で、補正後も唯一残ったが、確認期間で98%に落ちた
4. **3連複・3連単を比率で絞ると大負け（11〜41%）。** 人気薄同士の組み合わせを、確率の計算式（Harville）が高く見積もり過ぎる。3連系に広げるなら、計算式の補正が先
5. 採用基準（300レース以上・95%区間の下限>100%）を満たしたものは**まだ無い**

## これからの分析（データの穴を探す順番）

1. **3連系の確率の作り直し**: 3連複・3連単の確率を、実際の払戻に合わせて補正する（λ-Harville）。直したうえで、比率で絞る買い方をもう一度トーナメントに入れる
2. **買う時刻**: 発走35分前のオッズと確定オッズのずれを、自動運転の記録で測る。ずれが大きければ、締切に近い時刻で計算し直す
3. **市場が持っていない情報を足す**: 調教は採用済み。前日のバイアス・天気・文脈情報は効かなかった。次は乗り替わりの理由、馬体重の当日変化、休み明けの仕上がりなど、当日にしか出ない情報
4. **資金の配分**: 同じ候補でも、均等に賭けるかケリーで厚みを変えるかで収支が変わる（C1とC6の比較）
5. 新しい結果が入るたびに `--build` → 実行で、§4 の事前登録の成績を更新する
